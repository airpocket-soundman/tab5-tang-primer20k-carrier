## 独立確認

作業エージェントの自己評価に加え、親側で実回路図からXMLを出力し、PCBの端子接続・部品値・フットプリント・実装設定を照合した。M5-Busの確認済み左右、全204端子と新ソケット図面の位置、必須部品の実装、BOMとCPLの一致、指定品番、座標原点、PCB版と製造データのハッシュを検査した。DRCも親側で実行した。KiCad既定の無効検査種別は元版から増やしていない。

- A：[独立監査 32項目](validation/lite-a-dual-independent-audit.json)、[親側DRC](validation/lite-a-dual-drc.json)。
- B：[独立監査 32項目](validation/lite-b-barrel-independent-audit.json)、[親側DRC](validation/lite-b-barrel-drc.json)。
- C：[独立監査 27項目](validation/lite-c-dnp-independent-audit.json)、[親側DRC](validation/lite-c-dnp-drc.json)。

HDMIはA/Bの実PCBから再抽出し、510Ωを使って4ポートモデルを再計算した。主配線の連続性・全区間分類・既定の分岐ビアの整合も確認した。499Ω→510Ω単一抵抗はBasic化しつつ追加8部品と配線干渉を避けるための変更。伝達変化約0.01dB・受信DC変化約5.9mVで、変更感度は小さい。ただしCore・新ソケット・ESDの不確かさは残る。

## 発注時・実機で残る確認

- 新ソケットC22471982の在庫割当、予備数、治具費、PCBA実装可否と端子向きのプレビュー。5.2mm高さの筐体干渉は実物未確認。
- 4層積層は解析条件JLC04161H-7628（F.Cu→GND 0.2104mm）との一致を確認する。Gerberのみで積層が指定されるわけではない。
- 12Vセンタープラス電源を使う。外部3.3V給電は禁止、室内PoC・周囲50℃以下・通常LDO負荷10mA以下の条件。
- FPGAとTab5のGPIO設定を確認してARMし、低速パラレル通信→Core DDR3試験へ進む。実物での実行は未確認。HDMIは640×480から720p60へ、短いケーブルと限定モニタで試す。1080p60を目標にしない。

## HDMIの追加感度確認

新Aの実配線・510ΩでCore85/100/115Ω×ESD差動0.2/0.35/0.5pFを解析すると、9条件中1条件で自主反射目標−10dBを外れた。Core85Ω・ESD0.5pFのD2で約−9.17dB。さらに新ソケットのL/Cを仮置きした感度例では悪化する条件がある。[27条件の結果](validation/lite-a-dual-channel/uncertainty.json)。ソケットのL/Cは未校正の仮定で、全実物条件を包絡せず、不良率を表さない。HDMIの普遍的な動作保証とはしない。
