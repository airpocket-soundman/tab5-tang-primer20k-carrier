# 案A：99×78mm、HDMI・USB PD・バレル入力を保持

2026年10月25日。方法1・2・6・7とソケット変更を採用した独立設計。元の125×78mm版は変更していない。

KiCad回路図・実配線PCB・製造候補データを作成した。**DRC全項目0件、未接続0件、必須パラレル通信・電源32項目通過**。これはPoC用の設計検証であり、実機通信、DDR3初期化、HDMI規格適合を実証した結果ではない。ソケットの調達・治具費と業者実装プレビューは発注時に確認する。

## 成果物

- `kicad/tab5-fpga-carrier.kicad_sch`：案Aの回路図。
- `kicad/tab5-fpga-carrier.kicad_pcb`：実配線済み99×78mm・4層PCB。
- `kicad/bom.csv`、`core_pin_assignment.csv`：実装方針とCore端子割当。
- `manufacturing/lite-a-dual-2026-10-25/`：Gerber ZIP、ドリル、JLC BOM/CPL、組立図、手実装・未実装一覧、検査manifest。

PCBAは94部品・38行。J4の204ピン受け側ソケットはPCBA対象で、Core基板本体はBOMに含めない。J1・J3・J5・SW1〜3・JP1は従来同様の手実装対象。HDMIコネクタも後付けする。JLC BOMとCPLの実装部品集合は一致している。

HDMIバイアスは当初検討した2×1kΩから単一510Ωに変更した。二並列化で生じる新しい枝と狭い配置の干渉を避け、追加8部品の実装費も不要になる。499Ωからの+2.2%について親側の同一形状4ポート比較で差分を確認し、本案の実配線を510Ωモデルで再計算した。元の499Ω用の配線形状を保っており、D1分岐は各0.585mm、ESDは信号線からの銅分岐接続。

Coreソケットの204信号ランド、位置決め穴、金属固定ランドは[メーカー図面](../reference/socket-XDAP.pdf)を参照。U字の部品領域は本体図・カード幅から導出したもので、メーカー指定courtyardそのものではない。実物の挿抜、筐体との干渉、5.2mm高への変更は最終組立プレビュー・現物でも確認する。

L1の推奨ランドは中心±4.75mm、各4.1×4.95mm。[MS1040メーカー図面](../reference/MS1040-current.pdf)による。15µH±20%、Irms4.5A、Isat6A、DCR最大45mΩ。TPS5430と220µF POSCAPは保持し、出力フィルタの別方式への置換は行っていない。

## 必須機能と電源の確認

Tab5のD0〜D7・CLK・RDY・DIR・AUX0〜3は元の端子割当を保持する。15信号はSN74CB3Q3245を介して接続し、両電源監視・電源断保護・手動ARMを保持する。Tab5のHVINへはVINを供給する。Tab5の5V出力・VBAT_OUTをCore 5Vへ接続しない。JP1はGPIO所有権とファームウェア設定確認後にARMする。

3.3Vの負荷は、SN74CB3Q3245のICC最大2mA×2、DDCの10kΩプルアップ2本で約0.66mA、OEの22kΩで約0.15mA、合計約4.81mA。通常負荷を余裕込み10mA以下と見積もり、設計上限50mA、室内周囲50℃以下、外部給電禁止を条件とする。Core上FPGA／DDR3の電源はこのLDOから供給しない。

SN74CB3Q3245のICCは、VCC=3.6V、II/O=0、Switch ON/OFF、入力VCC/GNDの条件で最大2mA。[TI SCDS124C](https://www.ti.com/lit/ds/symlink/sn74cb3q3245.pdf)を参照。OEの高速反復切替では消費電流が増えるため、OEは電源監視とARMによる静的制御として扱う。U3の50mA上限は85℃周囲での連続動作保証を意味しない。

U3と入力C10／出力C11の実銅経路はそれぞれ約6.50／6.26mm、F.Cuのみ、ビア0、最小幅0.25mm。抵抗は約8.08／11.03mΩ。GNDの最寄りビアはU3から約0.85mm、各コンデンサから約1.08mm。メーカーの近接配置推奨に対して最短の配置ではないが、入力10µF／出力22µF、通常10mA以下の負荷、直下GND面と短い帰路を条件にPoCでは許容と判断した。`ldo_local_paths.json`に測定を保存した。LDOの安定性の実測・帰路インダクタンスのEM解析を行ったわけではなく、初回通電で3.3V起動・リップルを確認する。

R7の実抵抗網、各抵抗±1%、TPS5430の全温度Vref=1.196〜1.245Vを使った出力設定範囲は4.80709〜5.15745V。実配線のCore各端子までの最短経路抵抗は約0.104〜0.137Ω。全Core電流0.5Aを各単一路へ割り当てる保守的計算で、銅85℃感度を含めたCore端子下限は約4.721Vとなる。Core公式5V±10%内だが、ソケット接触抵抗・帰路抵抗・リップル・過渡応答は含めない。0.5AはCore公式の電源要求であり、実機の最大ピーク電流とは扱わない。

## 検査と限界

- `kicad/sim/drc_r3.json`：全severityのDRC 0件、未接続0件。検査を無効化して回避していない。
- `parallel_power_check.json`：M5-Busの向き、15信号の実銅接続、電源・ARM保護の32項目通過。
- `regression_parallel_power.json`：通常ケースと誤接続・抵抗網の故障注入を含む12ケース通過。
- `power_dc_check.json`：実配線の5V抵抗と新しい抵抗網の計算。
- `classification_report.json`：未分類・重複・古いrole・線幅不一致・未承認TMDSビア0件。
- `continuity_report.json`：全8信号のCore側／コネクタ側の銅配線が連続。
- `ground_reference_check.json`：TMDS主線・引き出し・ESDストラップの1820点で直下In1 GNDを確認。
- `tmds_sparam.json`：新PCBと510Ωによる4ポート近似解析。最悪SDD21は742MHzで約−0.87dB、1.5GHzで約−1.28dB。
- `erc-error.json`：回路図ERCエラー0件。全severityには生成シンボルのライブラリ差分と未使用ラベルの警告があり、実配線検査とは区別する。

HDMI解析は既存と同じJLC04161H-7628・1.6mm・F.Cu 35µm／In1まで0.2104mmのモデル条件を使う。Core・ソケット・コネクタを含むモデルは近似で、ソケット新品番の実測Sパラメータを取得したものではない。新規全面3D EM解析・HDMI認証試験は行っていない。最初の実機確認は低いHDMIピクセルクロックから進める。

初回自動配線では15ネットに未完があったが、22回の局所rip-upを経て132ネットを301秒で配線した。生成後の未接続はR4とU5のGNDだけで、既存主配線を変えず普通の0.5/0.3mmビアと短い銅配線で補修した。ソケットcourtyard追加後、SW2を左へ0.3mm動かして干渉を解消し、最終DRCを再実行した。

## 要求元と実機で残る確認

Linux `c1cd5e47f9f07a164bc070b8defe36bb05682c6b`、GPU `3b1ace3d91c6305ec0e32378f8819fce208c2aa7`、メモリ研究 `e4aa69d09b2643d6f62fe686ef0f3284b109c541`を照合した。Linux側の通信transportはmockで、物理PARLIO／DMAは未検証。GPUのboard profileもVERIFIED=0で、link wrapperは完成したDDR3接続topではない。

別ソフトウェア・別FPGAビットストリームで利用する。キャリアは通信・給電経路を提供し、Core DDR3初期化、Tab5実通信、GPU描画は適切なファームウェアとビットストリームで現物検証する。Linuxの透過的な主記憶増設を意味しない。
