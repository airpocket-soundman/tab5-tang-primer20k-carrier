# ESP32-P4 × Tang Primer 20K 共通ハードウェア仕様（プロジェクト骨子）

更新日：2026-10-26
状態：設計レビュー中。主電源改訂未完了、未製造・未実機検証。

## 目的
M5Stack Tab5（ESP32-P4）とTang Primer 20K Core（FPGA＋128MB DDR3）を、M5-Bus直挿し専用キャリアで接続する。共通のハードウェアを使い、以下の独立した2プロジェクトを進める。

1. NOMMU Linux向け外部メモリ管理・演算補助（仮想MMU研究）
2. Tab5向け外付け自作3D GPU

両者は**別のソフトウェア／FPGAビットストリーム**を前提とし、同時動作を初期要件としない。

## 主要構成

| 構成 | 選択・方針 |
|---|---|
| ホスト | M5Stack Tab5／ESP32-P4、32MB PSRAM |
| FPGA | Sipeed Tang Primer 20K Core |
| FPGA側RAM | Core搭載128MB DDR3 |
| キャリア | Tab5のM5-Busへ直接装着、Tang Primer 20K Coreを装着 |
| 通信（初期） | GPIO 8bitパラレル／ESP32-P4 PARLIO、DMA利用を目標 |
| 通信（将来） | 16bitパラレルを検討。Tab5の配線・競合確認が前提 |
| 電源入力 | 外部約12Vをキャリアへ供給 |
| Tab5電源 | キャリアからM5-BusのHVINへ供給 |
| FPGA電源 | キャリア上の独立12V→5V DC-DCからCoreへ供給 |
| 接地 | 共通GND。Tab5の5VレールとFPGA用5Vは直結しない |

## 8bit GPIO接続案（暫定）

| 信号 | Tab5 GPIO | M5-Busピン |
|---|---|---|
| D0～D7 | G18, G19, G5, G3, G4, G2, G48, G47 | 7, 9, 11, 19, 20, 21, 22, 23 |
| CLK | G16 | 2 |
| READY/IRQ | G45 | 8 |
| DIR | G51 | 26 |

**注意：**これは会話中の仮割り当てであり、Tab5回路図上のネット、PARLIO送受信切替、FPGAバンク電圧、GPIO起動状態、Linuxドライバで未確定。PCB発注前に必ず照合する。

**基板到着前のベンチ試験（2026-10-28追加）：**同じGPIO割当で、M5-Busと公式DockのJ12/J5/J14をジャンパ線でつなぐ構成と、Dock専用.cst案、段階試験、FPGA機能の分割方針を[Dockジャンパ試験](Dockジャンパ試験_配線とFPGA構成_2026-10-28.md)にまとめた。未合成・未実機。接続試験ビットストリームはESP-IDF・MeOS・Linuxで共通、アプリ用（GFX/NPU/MEM）は別とする。

## 共通FPGA基盤
- P4↔FPGA通信層：コマンド、アドレス、長さ、ペイロード、要求ID、CRC、割り込み／READY
- DDR3コントローラ：READ／WRITE／COPY／FILL、転送用FIFO
- 監視：通信エラー数、実効帯域、レイテンシ、DDR3テスト
- 用途別の上位回路：Linux用メモリ・演算機能／GPU描画機能

## 性能上の制約
- 8bit×40MHzの**理論最大**帯域は40MB/s。実効値はDMA、プロトコル、配線に依存。
- FPGA側128MB DDR3はP4から直接アドレス指定できる汎用メインRAMではない。
- P4が内蔵MMUを持たない問題は、外付けFPGAだけでは解消しない。
- Core側のDDR3はCore上で接続済み。キャリアでDDR3信号を引き回す必要はない。

## 2026-10-26 主電源仕様訂正

フル版125×78mmと廉価版A99×78mmに適用する。オルタネート式の押しボタンで外部給電をON/OFFする。DC12VとUSB PD12Vの保護・OR合流後、Tab5 HVINとCore用降圧入力への分岐前を一括して制御する。PD交渉回路は上流に残す。Tab5の内蔵バッテリーは停止対象に含めない。

既存SW3によるBUCK_EN接地はFPGA専用停止であり、この要求を満たさない。改訂では取り除く。リセット、ユーザーボタン、BUS ARMは別機能として維持する。現行のPCB・EasyEDA・解析結果を新しい主電源の検証済み資料として転用しない。

[詳細・参照版・実装状況](../spark/main-power-r2/README.md)。GPIO・通信プロトコルの変更は予定しない。電源断で通信が途切れるためソフトウェア側のタイムアウトと再初期化が必要だが、Linux/GPUとも物理経路での動作は未検証。関連リポジトリの仕様コピーへの反映は未実施で、本節を変更の起点とする。

## 2026-10-26 片面SMT優先への変更（現行）

ユーザー指示により両面SMTをやめ、主電源SW3を省略する。旧FPGA専用停止SW3も削除。
r3のU11/R53〜R58/C25/C26はr4に搭載しない。12V入力のOR・ヒューズ・TVSと常時有効な既存5V変換系を使う。
Tab5用J3は裏向きTHTのままLCSC C56496を別購入し手はんだ、PCBA対象から除外。SMTは表面のみ。
HDMI・USB PD・通信GPIO・ピン配列は変更なし。Linux/GPU用途の別ソフト・別ビットストリーム方針を維持する。
外部給電を基板上で切る機能はない。Tab5内蔵バッテリーの停止制御もない。
