FRACTAL_CONFIG37 retains a=iteration limit1..128. b is now two mode bits: bit0 Julia(1)/Mandelbrot(0), bit1 vivid palette(1)/legacy palette(0); all other bits must be zero. Arithmetic uses only bit0. New hosts must require FRACTAL_INFO flag0x10 before sending mode2/3; no automatic fallback that changes the requested image.

New27MHz image INFO is0117. The54MHz clock-query image uses021f. Existing capability/version semantics remain: version1 legacy27MHz; version2 requires clock query3d. Older exact-INFO validators may reject the added flag and need a codec update. Hosts that support extra capability bits and keep modes0/1 receive unchanged color/depth results. Old images do not advertise0x10 and reject mode2/3; the new host must detect this before drawing.
