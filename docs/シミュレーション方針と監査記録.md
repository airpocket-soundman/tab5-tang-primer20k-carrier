# HDMI（TMDS）シミュレーション — 方針と監査記録

> **2026-10-24 レビュー追記：本書の「合格（推定）」は保留。** [PoC向け妥当性レビュー](PoCシミュレーション_妥当性レビュー_2026-10-24.md)に、公式資料・実部品・実PCBを再確認した結果と製作条件を記録した。ESDの内部通過想定と長い抵抗枝は是正が必要。720p60を主目標とし、通常1080p60を必達にしない。TDR・アイ測定と完全なCoreの3D解析は、今回のPoCでは必須条件にしない。

## 1. 目的と合否基準

| 項目 | 基準 | 根拠 |
|---|---|---|
| 差動インピーダンス | 100 Ω ±15 %（85〜115 Ω） | HDMI 1.4 の TMDS 線路要求（通常の設計目標） |
| ペア内スキュー | < 5 mm（約 30 ps） | HDMI 設計ガイドの一般値。720p〜1080p で十分な余裕 |
| ペア間スキュー | TI SLLA414A §2.3: 0.20×Tcharacter（720p60 で約 2.7 ns）。参考として 17 mm 以内 | 以前の「規定なし」は誤り（§9 で訂正） |
| SDD11（反射） | 設計目標 ≤ −10 dB（〜1.65 GHz）。規格値ではない | HDMI のソース側反射は規格で細かく規定されないため、設計上の自主目標 |
| SDD21（挿入損失） | 損失が 1 dB 程度以内（目安） | 自主目標 |
| 対象信号速度 | **720p60 = 0.74 Gbps/lane を目標**。1080p60 = 1.49 Gbps/lane は GW2A のシリアライザ上限（1200 Mbps、DS102 Table 3-17）を超えるため対象外 | §9 で訂正（以前は〜1080p） |

合否の最終判断は**試作基板の実測**（TDR・アイパターン）で行う前提。本シミュレーションは設計段階の検討用。

## 2. 評価の範囲（決定事項と理由）

信号の全経路: FPGA パッド → **Core 基板内配線** → **SODIMM 接点** → **キャリア基板（キャップ・ESD・配線）** → **HDMI コネクタ** →（ケーブル → シンク）。

| 区間 | 扱い | 理由 |
|---|---|---|
| キャリア基板 | **実形状から解析**（主対象） | 自分たちの設計物 |
| Core 基板内 | 理想 100 Ω 線路（長さ 38.4 mm、εeff 3.0 仮定） | Core の配線データは非公開。公式の配線長表（`Core_3690_Net_Length.xlsx`）のみ入手可。長さは TX1/2/3/5 で 1510 mil ±5 mil、TX4 のみ N が 75 mil 短い |
| SODIMM 接点 | **集中定数の感度解析**（直列 L・並列 C を振る） | 公式に電気特性データなし。実測まで確定できない |
| HDMI コネクタ | 100 Ω・11 mm の理想線路 | 実形状モデルなし |
| ケーブル・シンク | **対象外** | HDMI の測定はコネクタ端子で行う規定 |

公式 Tang Primer 20K Dock の回路図（`docs/reference/tang-primer-20k/Dock_3713/3714_Schematics.pdf` 5/9）から、HDMI 回路の構成（100 nF AC 結合、499 Ω GND、RCLAMP0524P、SRV05-4）を採用した。**公式の基板配線データは非公開**のため、配線品質の直接比較はできない。

## 3. 計算手法とツール

| 層 | 手法 | 実装 | 状態 |
|---|---|---|---|
| (a) 解析式 | IPC-2141 / Hammerstad 式 | 手計算（検証用） | 参照値として使用 |
| (b) 2D 準静的 | 有限差分でラプラス方程式を解き、静電容量行列 → Z0 / Zodd / Zeven / εeff | `kicad/sim/microstrip2d.py`（自作、numpy/scipy） | **主力**。(a) と一致を確認 |
| (c) チャネル推定 | 区間（0.1 mm 刻み）ごとの局所 Zdiff を (b) の表から引き、ABCD 行列でカスケード。損失は tanδ 0.02 と表皮効果 | `kicad/sim/tmds_channel.py`, `tmds_sparam.py` | 主力。差動モードのみ |
| (d) 3D 電磁界 | FDTD（openEMS 0.37.0） | `kicad/sim/openems_lib.py`, `openems_test_*.py` | **較正中・結論には未使用**（§6） |

使用環境: KiCad 10.0.6（pcbnew で配線抽出）、Python 3.12.7（numpy 2.5.3 / scipy 1.18.1 / matplotlib 3.11.2）、
openEMS 0.37.0（公式配布 `openEMS_x64_v0.37.0_msvc.zip`、sha256 先頭 `e4f14fd6e9be7d0`、専用 venv: Python 3.13 + numpy 2.5.4。**ユーザー許可の上で導入**、プロジェクト外 `%LOCALAPPDATA%` に配置）。

### 3.1 スタックアップ（想定）
JLCPCB 4 層 JLC04161H-7628、1.6 mm: L1 銅 35 µm / プリプレグ 7628 0.2104 mm（εr 4.4）/ L2 / コア 1.065 mm（εr 4.6 を (d) で使用）/ L3 / プリプレグ 0.2104 mm / L4。
ソルダマスクは無視（Zdiff を 1〜3 Ω 下げる方向）。**実際の発注時の積層指定が上記と一致することの確認が必要**。

### 3.2 モデルの前提・簡略化（結果の解釈に必須）
1. 差動モードのみ。モード変換（コモン⇔差動）は評価しない。
2. F.Cu の区間だけ 2D で解く。In2.Cu・B.Cu の区間とビアは **100 Ω の線路**として扱う（ビア寄生は未考慮）。
3. 隣接配線・GND 島によるループ変化（In1 の GND ベタは健全と仮定）、アンチパッドの影響は未評価。
4. AC 結合キャップは ESL 1.4 nH（差動、2×0.7 nH）、ESD は差動 0.15 pF（0.3 pF/線の並列）。**ESD は入出力が内部でつながる素通しとしてモデル化したが、採用部品でその保証はない（§9 A）。容量も仮定（§9）。**
5. バイアス抵抗（499 Ω）の枝配線は信号経路から除外した。**誤り：枝は 21〜53 mm あり、並列負荷としても無視できない（§9 B）。**
6. HDMI コネクタ内部・SODIMM 接点は理想または集中定数。

## 9. 独立レビュー（別セッション、2026-10-24）の指摘と確認結果

別セッションが、この記録と解析コードを独立にレビューした。指摘のうち、**次の 2 点を自分でも確認し、設計の欠陥と認めた**。

### A. TMDS 用 ESD の端子導通の想定が誤り（試作前に必須の是正）
- 設計（`kicad/gen/design.py`）は U4/U5 を LCSC C293965 とし、10 ピンの入力（1/2/4/5）と出力（10/9/7/6）が部品内部でつながる素通しとして配線した。
- 確認: C293965 は **DOWO 製 RCLAMP0524P（DFN2510-10L）**。データシート Rev.G1.00 p.2 に「I/O pins are pin 1,2,4,5, GND pins are pin 3,8」とある。6/7/9/10 の内部導通は保証されない。公式 Dock の回路図の記号を根拠に別メーカー部品の内部導通は仮定できない。
- DRC・回路図の照合は部品内部の導通を前提にするため、この誤りを検出しない。
- 対応: 信号線を PCB 上で連続した銅配線にし、ESD は分岐（シャント）で接続する。または内部導通が仕様で保証された部品へ変更。変更後に再配線・再抽出・再解析。

### B. 499 Ω バイアス抵抗の枝配線が長い
- 確認（実配線）: 枝の長さは D0P 21.0／D0N 23.3／D1P 20.9／D1N 31.7／D2P 29.8／D2N 32.3／CKP 29.2／**CKN 53.5 mm**。P/N で非対称。`stub_tracks.json` は CKN の枝を記録できていなかった（解析の記録漏れ）。
- 以前の「DC のみで高周波では開放に近い」は誤り。差動 998 Ω の並列負荷だけで SDD21 約 −0.43 dB、SDD11 約 −26 dB（レビューの試算）。53 mm の枝は約 0.8 GHz で 1/4 波長に相当する。
- 対応: 抵抗を信号線の分岐点の近く（数 mm 以下、可能なら 1〜2 mm）へ置き直し、P/N を対称にする。枝は解析に含める。

### C. その他の訂正・追記
| 項目 | 訂正 |
|---|---|
| ペア間スキュー | 「規定なし」は誤り。TI SLLA414A §2.3: ペア内 0.15×Tbit、ペア間 0.20×Tcharacter（720p60 で約 200 ps／約 2.7 ns）。5 mm は自主的な保守目標 |
| 対象速度 | 通常の 1080p60（1485 Mbps）は GW2A のシリアライザ上限 1200 Mbps を超える。**720p60 に限定**。1080p30 は同じ線路速度でもモニタ対応の別確認が必要 |
| ESD 容量 | 差動 0.15 pF は根拠が弱い。DOWO 資料は I/O−GND typ.0.4/max.0.5 pF、I/O−I/O typ.0.2/max.0.3 pF。差動 0.2〜0.5 pF を**仮定の感度範囲**として使う |
| 差動インピーダンス | 実間隔 0.13 mm の直接解は約 103〜104 Ω。107 Ω は 0.15 mm の値の代用だった（§6.4 で訂正済み） |
| Core の影響 | 長さ一致だけでは 100 Ω の証明にならない。Core 側を 85〜115 Ω に振ると、720p 帯で SDD11 が −12〜−16 dB 程度まで悪化する（レビューの試算） |
| 公式の基板データ | 「非公開」ではなく「未取得・公開確認できず」と表現する |
| チャネル推定の合否 | 内層・ビアの 100 Ω 置換、ESD の素通し、枝の除外を残した推定から「合格」と断定できない。**§5.2 の表現を訂正** |
| 区間の順序 | レビュー時点のコードは Core 側を単純に逆順にしており、電気的な経路順ではなかった。本記録の §6.4 のとおり、接続をたどって並べる方式に修正済み |
| 3D 解析 | 較正未了で採用しない判断は妥当。2D 値に合うまで調整することは検証ではない |

### D. 目標の再設定（PoC）
- 目標は量産品質ではなく、**短いケーブル・限定したモニタでの 720p60 の表示確認（30 分程度）**。動作保証・全機器互換・HDMI 規格適合は意味しない。
- Core 全体の 3D 解析、HDMI 認証、試作前の TDR・アイ測定は、今回の製作条件としては必須としない（不調時の切り分け・次版の改善用）。
- 製作前に残す確認: ESD の実部品・端子・フットプリント、P/N と D2 の反転方針（TMDS エンコード後・差動バッファ前の全シリアルビットを反転）、499 Ω 枝の短縮、積層指定（JLC04161H-7628）、電源・機構の確認。

> 本節の元になったレビュー文書は別セッションの作業物で、この記録のコミットには含めていない。数値の根拠となる再計算は、本記録の §6 および `kicad/sim/` のスクリプトで再現できる範囲に限る。
