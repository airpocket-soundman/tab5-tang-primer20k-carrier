# r5s：SW4をロードスイッチ式にする検討（回路案とSPICE検証）

2026-11-06 / 検討: Claude / 状態: **机上検討とSPICEに続いて、変種 r5l（`spark/usb-jtag-r5-loadsw/`）として回路図・基板・発注データまで作成済み（下の「実装（r5l）」）。実機未検証。r5lのJLCPCB見積もりは $170.10（r5sは $168.83、+$1.27）。**

## 背景（なぜ変えるか）

- SW4（G-Switch SS-23D03-G080、C2848921）の電流定格は、データシート原本で **0.3A・50V DC**（LCSCの掲載値1Aは原本と食い違う）。
- SW4は+5Vレールの全電流を通している。+5Vの負荷は、Core（J4の4〜7番）、3.3V LDO（U3）、FT232H（U17）、監視IC（U10）、HDMI 5V（F2は500mA保持のPTC）。合計は0.3Aを超え得る（未測定）。
- DP3Tのスルーホールのスライドスイッチで、同じ形状のまま1A以上の品は見つからなかった（ほぼ0.3〜0.5A）。
- そこで、SW4は**信号だけ**を切り替え、+5Vの電流はPMOSに通す案を検討した。
- JP3（Tab5給電）はVIN系統で、+5Vではない。SW4の負荷には含まれない。

## 回路案

SW4のピンの割り当て（フットプリントは同じ、配線だけ変更）:

| SW4 | 現行 | ロードスイッチ式 |
|---|---|---|
| pad4（A極の共通） | +5V | **GND** |
| pad1（RUN） | BUCK_5V | **ゲート駆動 RUN_G**（Rd 4.7kΩ経由でRUN経路のゲートへ） |
| pad3（PGM） | VBUS_PD | **ゲート駆動 PGM_G**（Rd 4.7kΩ経由でPGM経路のゲートへ） |
| pad5・pad8（B極：CFG1とGND） | 同じ | 変更なし |

経路（どちらもソース同士をつないだ背中合わせのPMOS 2個）:

- **RUN経路:** Q_r1（ドレイン=BUCK_5V）、Q_r2（ドレイン=+5V）。ソース共通=SCR。ゲートは100kΩでSCRへ上げ、SW4 RUNで4.7kΩ経由のGNDへ下げる。
- **PGM経路:** Q_p1（ドレイン=VBUS_PD）、Q_p2（ドレイン=+5V）。ソース共通=SCP。ゲートは100kΩでSCPへ上げ、SW4 PGMで4.7kΩ経由のGNDへ下げる。
- **PGM経路の過電圧ガード:** Q_k（PMOS、ソース=SCP、ドレイン=PGM経路のゲート）。ゲートは10kΩでSCPへ上げ、ゼナー6.2V（カソード=Q_kのゲート、アノード=GND）でクランプ。SCPが約7Vを超えるとQ_kが入り、PGM経路のゲートをSCPへ引き上げて強制オフにする。

背中合わせにする理由: ボディダイオードが互いに逆向きなので、(1) VBUS_PD側へ+5Vが逆流しない、(2) BUCK_5V側へ逆流しない、(3) ソース共通の節点が自動的に高い方の電圧になり、ゲートの上げ先として使える（別のOR用ダイオードが要らない）。

追加部品: AO3401A（C15127）5個、BZT52C6V2（C19077403）1個、100kΩ（C25803）2個、4.7kΩ（C23162）2個、10kΩ（C25804）1個。合計11点。いずれもC案（r5c）で採用済みの型番。

## SPICE結果（`../spark/usb-jtag-r5-loadsw/sim-spice/`）

汎用の簡易モデル（AO3401A: VTO=-0.9V、KP=4.07、ゼナーはNBVでドループを表現）で、メーカーのSPICEモデルではない。負荷は5Ω（約1A）。

| ケース | 結果 |
|---|---|
| RUN、USB 12V＋DC | +5V＝4.83V（1A）。VBUSへの逆流 0.1mA以下 |
| RUN、DCのみ | +5V＝4.83V |
| OFF（両方の電源あり） | +5V＝0V |
| PGM、VBUS 5.0V／5.5V | +5V＝4.83V／5.32V（1A）。BUCK側への逆流 0 |
| PGM、DCのみ（VBUS=0） | +5V＝0V。逆流 0 |
| **PGM、VBUS 12V（誤使用）** | **+5V＝0V**（ガードなしだと11.8V） |
| PGM、VBUS 5V→12Vのステップ（1ms） | +5Vのピーク 6.7V（公称）。16コーナー: 5.46〜7.74V |
| PGM、VBUS 0→15Vのスローランプ | +5Vのピーク 16コーナー: 5.50〜7.75V |
| 5.5V給電での誤遮断 | 全16コーナーで誤遮断なし（+5V最小 5.27V） |

16コーナー＝PMOSのしきい値（-0.6/-1.3V）、ゼナー±5%、ゼナーのドループ（NBV 1/6）、温度（-20/85℃）の全組合せ。

読み方:

- **1Aでの電圧降下は約0.17V**（PMOS 2個分＋電源の内部抵抗0.05Ω×2）。現行のSW4直結（接点抵抗のみ）より大きい。
- **ガードのピークは最大7.7V。** 保険であり、+5Vレールの瞬時7V超は残る。Coreの5Vピンの絶対最大定格は未確認で、C案の遮断窓（5.7〜7.3V）と同程度。
- 検出抵抗を100kΩにすると、ゼナーのリークで5.5Vの一部コーナーで誤遮断した。10kΩにして解消した。

## 見つかった別件（現行のr5s）

現行のr5s（SW4直結）では、**RUNからPGMへ切り替えた直後、VBUS_PDがまだ12Vのまま+5Vに接続され得る。** PGMではCFG1を開放（5V要求）にするが、CH224Aが5Vへ再交渉するまでの時間は未確認。回路図の検査は静的な組合せだけで、この過渡は見ていない。ロードスイッチ式のガードは、この点も保護する（上の「PGM、VBUS 12V」の行）。

## 未確認・制約

- 汎用モデルの机上値。メーカーモデルでも、実機でもない。
- **突入電流:** PGMで切り替えた瞬間、+5Vの容量へ、AO3401Aの低抵抗でほぼ直接つながる。USB側の電流制限に当たる可能性がある（未評価）。ゲート・ソース間に容量を足して、立ち上がりを遅くする余地がある。
- **ゲートの耐圧（AO3401A: ±12V）:** ガードが働かない状態でPGMを選び、VBUSが12Vだと、Vgs=-11.4V。許容内だが余裕は小さい。
- 回路図・基板・BOM・CPL・見積もりは、上の「実装（r5l）」で反映済み。部品はSOT-23／0603／SOD-123で、全部上面実装。
- AO3401A（C15127）、BZT52C6V2（C19077403）の在庫・価格は、今回確認していない。
- CH224AのPG出力（PD_PG）を使い、「5Vに交渉済みのときだけPGMを許可」する方法もあるが、PGの動作は未確認のため、今回は使っていない。
