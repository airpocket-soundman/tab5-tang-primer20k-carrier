# r5s：CH224K→CH224A差し替えの検証と設計への反映

2026-11-06 / 検証・反映: Claude / 入力: `spark/usb-jtag-r5-switch/order/quote-jlcpcb-2026-11-06.md`（JLCPCB見積もり。CH224K在庫切れ、CH224Aへの差し替え提案）

## 結論

**差し替えは妥当。ただし、見積もり側の分析に1か所の見落としがあり、設計にもう1点の変更が要る。** 次の3点を、r5s（B案）の回路図・基板・BOM・発注データに反映した。

| # | 変更 | 区分 |
|---|---|---|
| 1 | U1 CH224K（C970725）→ **CH224A（C42459160）** | 見積もり提案どおり |
| 2 | R1 10kΩ → **0Ω**、R2 1kΩ → **0Ω**（どちらもC21189、0603のまま） | 見積もり提案どおり |
| 3 | **SW4のpad6（PROGRAM側、旧PD_VDD）を未接続にする** | **今回追加（見落としの修正）** |

## 検証の根拠（WCH公式データシート CH224 V2.1）

`atta.szlcsc.com` で配布されているWCH公式資料（中国語）の本文を、直接読んで確認した。

| 項目 | データシートの記載 | 判定 |
|---|---|---|
| ピン互換 | CH224AはCH224Kとピン互換。多くの場合、PCBを変えずに周辺部品の変更で置き換えられる（5.1、第7章） | 提案と一致 |
| 1番ピン | A: **VHV（耐圧32V）**、K: VDD（耐圧3.6V）（7.1） | 一致 |
| VBUSピン | A: 電圧検出入力で、**VHVに短絡が必要**（表4-1）。K: 抵抗を介して外部VBUSへ（表4-2） | 一致 |
| 置き換え手順（I/O電平配置） | R1を0Ωに（または短絡）、R2を0Ωに（または短絡）（7.2.2） | 一致（R1、R2とも0Ω） |
| 12V要求 | I/O電平配置で CFG1=0、CFG2=0、CFG3=1 → 12V（表5-2） | 本基板と一致 |
| CFG2、CFG3の内部 | Aは内蔵プルアップ（7〜15kΩ）。Kは内蔵なし（7.1、8.2.1） | CFG3は未実装のR4のまま「1」。CFG2はR5（0Ω）でGND固定 |
| LCSC記号のピン名 | 1=VHV、2=CFG2/SCL、3=CFG3/SDA、4=DP、5=DM、6=CC2、7=CC1、8=VBUS、9=CFG1、10=PG、11=GND | データシートと一致 |
| VHVの範囲 | 3.3〜30V（絶対最大32V）（8.1.1、8.2.1） | 12Vでも余裕あり。1µF（C2、50V）は耐圧も十分 |

**見積もりの「Aの設定表はKと同じ」という記述は、12Vについては正しいが、一般には正しくない。** Aの表は、20V（CFG1=0、CFG2=1、CFG3=1）、28V（0、1、0）で、Kの表（15V＝011、20V＝010）と異なる。本基板は12Vと5Vだけを使うので影響はない。

## 見落とし：CFG1の絶対最大定格

- **CH224AのCFG1の絶対最大は3.8V**（8.1.1）。**Kは8V**（8.1.3、7.1）。
- データシートは、CFG1を高にする方法として、「**100kΩを介してVHVへ上拉**」（5.2.2、6.1.2）、またはMCUのGPIOを使う方法だけを許している。**VHVへの直結は、許されていない。**
- r5sは、SW4のPROGRAM位置（pad3とpad6）で、CFG1を、PD_VDDへ**直接**つなぐ設計だった。KのときのPD_VDDは、チップが作る約3.3Vだったので、問題なかった。**AでR1を0Ωにすると、PD_VDDはVBUSそのもの（5V、PD後は12V）になる。** PROGRAMでは、CFG1に5Vが直接かかり、絶対最大3.8Vを超える。
- 見積もりの文書は、「CFG1: SW4＋R73（100kΩプルアップ）のままでよい」としていたが、**スイッチが直結していた点を考慮していなかった。**

### 対策（反映済み）

SW4のpad6（PROGRAM側）を、**未接続**にした。

| SW4の位置 | 極Bの共通（pad5=CFG1） | CFG1の状態 | 要求電圧 |
|---|---|---|---|
| RUN | pad8＝GND | GND（0） | 12V（CFG2=0、CFG3=1） |
| OFF（中央） | 開放 | R73（100kΩ）でVHVへ（1） | 5V |
| PROGRAM | **開放（変更）** | R73（100kΩ）でVHVへ（1） | 5V |

- R73が、データシートの推奨そのもの（100kΩでVHVへ）になった。
- どの位置でも、CFG1は、GNDか、100kΩ経由のVHVだけにつながる。検証スクリプトに、「CFG1は、スイッチでGND以外につながらない」検査を追加した。
- 基板では、pad6へ向かっていた配線（13個の配線とビア。旧JP4の位置からの引き回し）を削除した。**PD_VDDの他の接続（U1、C2、R1、R73）は、残っている。**

## 反映した内容

| 対象 | 変更 |
|---|---|
| 回路図 | U1を `carrier:CH224A`（新規の記号、ピン1＝VHV）に。R1、R2＝0Ω。SW4のpad6＝未接続。注記を更新 |
| 基板（KiCad） | SW4のpad6のネットを外し、専用の配線を削除。U1・R1・R2の値を更新。**部品位置、他の配線は変更なし** |
| BOM（`jlc-bom.csv`） | U1＝CH224A（C42459160）。R1、R2、R5が、同じ行（0Ω、C21189）にまとまる。見積もりで使われたBOMと、同じ内容 |
| CPL | CH224Aの公式フットプリントで再計算。U1の位置・向きは、Kのときと同じ（残差0.36mm。露出パッドのランド寸法差による） |
| 発注データ一式 | ガーバー、ドリル、補正記録、発注条件を、同じ基板ファイルから再生成 |
| 検証 | ERCエラー0、DRC違反0・未配線0。回路の検査に、CH224A用の項目（R1、R2、R5、R4の状態、CFG1の保護）を追加 |

**見積もりの金額は、変わらない見込み。** 見積もりで使ったBOM（CH224A、R1・R2＝0Ω）と、BOMが同じなため。ガーバーは、配線の削除で、わずかに変わっているため、**発注前に、最新の `gerbers.zip` で、見積もりを取り直すこと**。

## 未確認・注意

- データシートは中国語の原本を、直接読んだ。英語版の確認、WCHへの問い合わせは、していない。
- **CH224Aの実物で、12V要求・5V要求が出ることは、実機で確認していない。** 実機試験（PDアダプタでの電圧測定）が必要。
- RUNでCFG1をGNDへ直結する点は、データシートの「0は、外部でGNDに短絡」と一致する。
- CH224AのI2C機能（CFG2/CFG3）は、使わない。CFG2はGND固定のため、I2Cは使えない。
- **r5（現行）と、C案（r5c）は、CH224Kのままで、変更していない。** r5sだけを更新した。
- 見積もりの記録（`quote-jlcpcb-2026-11-06.md`）は、そのままにしてある。見積もり時のBOMは、今回の設計と同じ。
- 見積もりが示した他の事項（スルーホール部品も、JLCPCBが実装すること、手はんだ費$3.61、U10が個人在庫から実装されること、$140クーポン）は、設計に影響しない。
