# PC移行時の再開手順（2026-11-03）

必要なリポジトリは本キャリアと`airpocket-soundman/tab5-fpga-gpu`。両方のmainを取得する。
FPGA実装は`5071406`、Tab5実装・書込みデータはGPU側`f8e978f3127e15200942305dc6b5f2aa8bc4f937`にコミット済み。
MeOSの既存LINK確認は`tab5-meos-fpga`の`26c8082`に記録済み。現在のTab5はESP-IDF診断へ切替済み。
Linux・メモリ研究側に今回の変更はない。

## 現在地とハードウェア

三角形5 DRAWの同じシーンを2段階で色・深度各1,024画素照合し、両方式とも一致。
単画素読戻し23.689843秒、行32word読戻し3.829592秒。通信CLKは最大5kHzのまま。
GPU全体やFPGA演算の高速化は未測定。[生ログ・ハッシュ](../fpga/validation/triangle-row-2026-11-03.json)を参照。

終了時Tab5は`armed:false`、DIP位置1は最後の操作ではON。
PC移行・再書込み前にDIP位置1をOFFにする。成功した配線は維持する。
USBを抜くとFPGAのSRAMイメージは消えるため、移行先で再ロードが必要。
Tab5のFlashは電源断後も残る。追加のファームバックアップはユーザー指定により不要。
COM番号は移行先で再確認する（旧PCはTab5 COM4、Dock UART COM27）。

## 実機確認済み書込みデータ

- FPGA: `fpga/validation/artifacts/triangle-row-2026-11-03.fs.gz`。同名JSONにFSのSHA-256と対象を記録。
- Tab5: GPU側`bringup/artifacts/triangle-row-2026-11-03.tar.gz`。
  bootloader・partition・app・flash_args・manifest・sdkconfigを収録。
  ESP32-P4 rev1.3、16MB/DIO/80MHzで確認。app SHA-256は
  `da8905e200f5c5a62052c9079095e1d34ebf3f39f0cca69d47b69e4acfd0db80`。

FSの展開例（キャリア直下）:

```powershell
python -c "import gzip,pathlib; p=pathlib.Path('fpga/validation/artifacts/triangle-row-2026-11-03.fs.gz'); pathlib.Path('triangle-row.fs').write_bytes(gzip.decompress(p.read_bytes()))"
```

公式Gowin Programmer V1.9.12.04を別途用意し、そのbinディレクトリから展開FSの絶対パスを指定する。
既存FTDIドライバで成功しており、ドライバ変更は不要だった。

```powershell
./programmer_cli.exe --scan --cable-index 1 --frequency 2.5MHz
./programmer_cli.exe --device GW2A-18C --operation_index 2 --cable-index 1 --frequency 2.5MHz --fsFile D:/path/to/triangle-row.fs
```

operation 2はSRAM書込み。Flash書込みへ変更しない。UserCode `0x00009137`、Status `0x00006020`を確認。
再ビルドは[三角形タイル試験](Dock三角形タイル試験.md)と`fpga/builds/dock/build_oss.py triangle`を参照。

## 試験の再開

1. DIP位置1をOFFにして、両機の起動とFPGAロードを確認。
2. Tab5コンソールの`status`で`profile:dock-jumper-v0`、`triangle_bulk_available:true`を確認。
3. `arm dock-jumper-v0`を送り`armed:true`を確認してから、ユーザーがDIP位置1をONにする。
4. `triangle-bulk`を送り、`triangle_pass:true`、`lcd_submitted:true`を確認する。
5. テスト終了後`status`で`armed:false`を再確認。

旧方式は`triangle`。JSONの`readback_mode`はそれぞれ`row32`と`pixel`。
ESP-IDF診断のコマンドは1行まとめて送る。1文字ずつ間を空けると現在のfgets処理で部分行として扱われる。
次はクロックを段階的に上げ、CRC・全画素一致・所要時間を測る。DMA、DDR3、GPU LAB全画面統合は未実施。
