# HDMI（TMDS）信号品質 — 調査と方針

> **2026-10-24 レビュー追記：従来の「合格（推定）」を製作承認には使わない。** 採用ESDのNC端子、長い499Ω抵抗枝、GW2Aの速度上限を確認した。[PoC向け妥当性レビュー](PoCシミュレーション_妥当性レビュー_2026-10-24.md)を最新の判断として参照する。Coreの完全な3D解析やTDR測定はPoC製作の必須条件とせず、具体的な接続・枝配線の修正後に720p60を狙う少数試作を検討する。以下は設計経緯の記録。

作成: 2026-10-23 / 対象: kicad/ キャリア基板 v1.x（Core を M-Bus の右へ、HDMI 上辺）

## 1. 公式 Tang Primer 20K Dock の HDMI 回路（参考にした点）

出典: `reference/tang-primer-20k/Dock_3713/3714_Schematics.pdf` の 5/9 ページ（`Dock_HDMI_sheet.png`）。
公式ドックは KiCad 9 で設計されている（図枠より）。基板（.kicad_pcb）自体は公開されておらず、**回路図 PDF のみ**。

| 項目 | 公式ドックの回路 | このキャリア基板（変更前） | 方針 |
|---|---|---|---|
| FPGA 出力 → | 0 Ω 直列（実装オプション）→ **100 nF AC 結合（各線）** | 直結 | **AC 結合 100 nF ×8 を追加** |
| コネクタ側のバイアス | **499 Ω で GND（各線 ×8）** | なし | **499 Ω ×8 を追加**（Basic 部品） |
| 差動間 | 100 Ω（各ペア、実装オプション） | なし | 100 Ω ×4 を追加（DNP 可） |
| ESD（TMDS） | **RCLAMP0524P ×2**（4ch、10 ピン） | なし | 採用。JLC **C293965**（Extended、在庫 7.5 万） |
| ESD（DDC/HPD） | **SRV05-4** ×1（SOT-23-6） | なし | 採用。JLC **C13612**（Extended、在庫 10 万） |
| DDC | 2N7002 ×2 によるレベルシフト、1.5 kΩ プルアップ（3V3 側）、27 kΩ/1.5 kΩ（5V 側） | 同等（2.2 kΩ） | 現状維持（検討済み） |
| HPD | 22 Ω 直列 + 5.1 kΩ + 10 kΩ GND + 2.2 µF | 10 kΩ/20 kΩ 分圧 | 公式の構成に寄せる |
| 5V / 3V3 | 1N5819WS で OR、10 µF + 100 nF | PTC + 0 Ω 系 | 現状維持（5V は PTC 経由） |

結論: **AC 結合 + 499 Ω GND バイアス + ESD** が公式のやり方。直結は採用しない。

## 2. Core 基板側の TMDS ペア（公式 Net_Length 表より）

`Core_3690_Net_Length.xlsx`: Core 基板内の配線長（FPGA ボール → SODIMM）。

| ペア | P 長 | N 長 | ペア内差 |
|---|---|---|---|
| TX1 | 1475 mil | 1476 mil | 0.6 mil（良） |
| TX2 | 1476 mil | 1476 mil | 0.6 mil（良） |
| TX3 | 1472 mil | 1475 mil | 3 mil（良） |
| **TX4** | 1476 mil | **1401 mil** | **75 mil = 1.9 mm（悪い）** |
| TX5 | 1476 mil | 1475 mil | 1 mil（良） |

- Core 内の各線は約 1510 mil（38.4 mm）で揃っており、**ペア間スキューは Core 側ではほぼ無い**。
- **TX4 は N が 1.9 mm 短い**（TMDS 720p のビット時間 ≈ 1.3 ns ≈ 200 mm に対し 1.9 mm ≈ 11 ps で実害は小さいが、避けられるなら避ける）。
- 方針: **D0 を TX4 → TX5 に変更**（TX1/2/3/5 を使用）。

## 3. シミュレーションの範囲（決定）

**キャリア基板側のみを一次対象とする。Core 基板側は直接は解かない。**

理由:
1. Core 基板の配線データ（.kicad_pcb 等）は非公開。得られるのは配線長（上表）のみで、3D 電磁界の入力にならない。
2. Core 内は「長さが揃った一様な差動線」として扱える（長さ 38.4 mm、ペア内/ペア間とも差が小さい）ので、**キャリア基板の S パラメータにカスケードする理想伝送線路（Z 100 Ω、長さ 38.4 mm、εr_eff≈3.1 想定）として加える**。
3. 問題の本体は、キャリア側の構造（トレース幅/間隔、ビア、AC 結合コンデンサ、ESD、HDMI コネクタパッド、SODIMM 接点）にある。

二段構成:

- **段階 1（基板単体）**: 各 TMDS ペアを切り出し、(a) スタックアップから微細線路の差動インピーダンスを算出（2D）、(b) 配線実形状を 3D 電磁界で解いて S パラメータ・TDR（ポート: SODIMM パッド ↔ HDMI コネクタパッド）。
- **段階 2（チャネル）**: 段階 1 の S パラメータに Core 側の理想線路（38.4 mm）と FPGA ドライバ/シンクの終端（HDMI シンク 50 Ω to 3.3 V）を加え、scikit-rf でカスケードし、反射・挿入損失・（可能なら）アイを評価。

合否の目安（HDMI 1.4、TMDS 720p〜1080p）:
- 差動インピーダンス 100 Ω ±15 %（HDMI 規格は 100 Ω ±15 %）。
- ペア内スキュー < 5 mm（< 約 30 ps）。
- 1.65 Gbps（720p60 ×10 ビットシリアル）で SDD21 の減衰が小さく、SDD11 が良好。

## 5. 結果の使い方

シミュレーション結果 → 配置・ルートの修正（線幅/間隔、ペア内長さ合わせ、ビア数、スタブ長、AC 結合コンデンサの位置など）→ 再配線 → 再シミュレーションを繰り返す。結果は本ファイルに追記する。

## 6. 結果 1: 現行ルータ（P/N を個別に配線）のベースライン — 2026-10-23

ツール: `kicad/sim/microstrip2d.py`（2D 準静的解、JLC04161H-7628 想定: L1–L2 間 0.2104 mm、εr 4.4、銅 35 µm）、
`kicad/sim/tmds_channel.py`（配線実データから区間ごとの Zdiff とペア長を算出）。

2D ソルバの検証: 単線 w=0.35 mm で Z0 = 51.7 Ω（JLCPCB の公表 50 Ω 用線幅と一致）。

| 線幅 / 間隔 | Zdiff | 備考 |
|---|---|---|
| 0.127 / 0.127 mm | 124 Ω | 現行の最小幅ペア（結合させた場合でも 100 Ω の +24 %） |
| 0.150 / 0.150 | 120 Ω | |
| 0.200 / 0.200 | 116 Ω | |
| 0.200 / 0.150 | 107 Ω | |
| 非結合（間隔 > 1.5 mm） | 約 165 Ω | 実配線の長さ加重平均は 153–163 Ω |

→ **100 Ω ±15 % にするには線幅 ≥ 0.2 mm・間隔 ≤ 0.15 mm 程度のペア配線が必要。**

現行配線の実測（Core 側 + コネクタ側の合計）:

| ペア | P 長 | N 長 | ペア内スキュー | Zdiff（平均） | 結合区間 |
|---|---|---|---|---|---|
| D0 | 38.1 mm | 34.8 mm | 3.3 mm | 162 Ω | 5 % |
| D1 | 56.4 | 45.5 | 10.9 | 162 | 5 % |
| D2 | 49.0 | 62.1 | −13.1 | 153 | 7 % |
| CK | 67.9 | 56.2 | 11.7 | 163 | 6 % |

→ **不合格**。P/N が並走せず（結合 5–7 %）、Zdiff は約 160 Ω（+60 %）、スキューは最大 13 mm（目標 < 5 mm）。
原因: 現行ルータは各ネットを独立に A* で引くため、ペアとしての結合・長さ合わせを一切考慮していない。

### 方針（結果を受けた配置・ルートの改良）
1. **ペア配線ルータを実装**: P/N を中心線 1 本（幅 = 2w + g）として配線し、後で 2 本に分割（コーナーは 45° 斜め）。ビアは 2 本を並べた「ペアビア」。パッド近傍はネックダウン。
2. 線幅は 0.2 mm / 間隔 0.13 mm 程度を既定とし、2D ソルバで Zdiff を再確認（目標 100 Ω ±15 %）。
3. ペア内の長さ合わせ（蛇行 < 5 mm 差）。
4. 再配線 → `tmds_channel.py` で再評価。

## 7. 結果 2: ペア配線ルータ導入後（最終配線） — 2026-10-23

実装: P/N を中心線 1 本（幅 2w+g = 0.53 mm）として配線し、±0.165 mm の 2 本に分割（w=0.2 mm、ペア内間隔 0.13 mm）。
Core 側は **入れ子の縦レーン**（D2→D1→D0→CK の順に x = 91.4 / 92.9 / 94.4 / 95.9 mm）、キャップ→ESD→コネクタ間は**水平の直線レーン**。
層替えは 2 本並べたビア（コーナーでは二等分線方向に 0.47 mm 以上）。TMDS を最優先で先に配線。
ESD の入出力ピンを HDMI の差動ペア位置に揃えて配置（直線レーンにするため）。FPGA 側は D2 の P/N 入替（TX5）。

最終配線（121/121 ネット、DRC 違反 0、未接続 0）:

| ペア | P/N 長 | スキュー | 結合区間の Zdiff | F.Cu 上の結合割合 |
|---|---|---|---|---|
| D0（TX2） | 53.2 / 53.2 mm | 0.00 mm | 約 104 Ω | 89 % |
| D1（TX3） | 35.2 / 35.2 | 0.00 | 約 104 Ω | 83 % |
| D2（TX5, P/N 入替） | 35.3 / 35.3 | 0.00 | 約 104 Ω | 83 % |
| CK（TX1） | 53.9 / 53.9 | 0.00 | 約 104 Ω | 77 % |

チャネル推定（`kicad/sim/tmds_sparam.py`、差動モード、Core 内は 100 Ω・38.4 mm の理想線路、ESD 0.15 pF 差動、キャップ ESL 1.4 nH、コネクタ 100 Ω・11 mm）:

| ペア | SDD11（0.825 / 1.65 GHz） | SDD11 最大（〜3.3 GHz） | SDD21（0.825 / 1.65 GHz） |
|---|---|---|---|
| D0 | -23.7 / -18.0 dB | -15.5 dB | -0.37 / -0.74 dB |
| D1 | -20.1 / -31.8 dB | -14.5 dB | -0.34 / -0.56 dB |
| D2 | -20.1 / -31.5 dB | -14.2 dB | -0.34 / -0.56 dB |
| CK | -20.2 / -14.4 dB | -12.8 dB | -0.40 / -0.86 dB |

評価: 差動インピーダンス（結合区間 ≈ 104 Ω、許容 100 Ω ±15 %）、ペア内スキュー（0.00 mm、許容 < 5 mm）は目標内。720p60（0.74 Gbps/lane）〜1080p60（1.49 Gbps/lane）の帯域内で、反射は −14 dB 以下（最悪 CK の 1.65 GHz で −14.4 dB、全帯域の最大 −12.8 dB）、挿入損失は 1 dB 未満（推定）。

### 残る不確かさ（次の段階）
- ビア・内層区間・ESD/キャップのパッド・HDMI コネクタ接続部は、準静的モデルでは**集中定数/100 Ω 近似**。実形状の 3D 電磁界解析が必要。
- **openEMS は pip では入らず、Windows 用バイナリのダウンロードが必要**（Docker は入っているがデーモン未起動）。インストールはユーザー確認の上で実施する。
- Core 基板内の配線は公式の長さ表のみ。Core の実差動インピーダンスは不明（100 Ω と仮定）。
- ペアのコーナー・ビアでの局所的なインピーダンス不連続（短い区間）は未評価。

### ルータ改良の記録（再現のため）
- ペア配線: `route_pair`（太い線→2 本分割、ペアビア、極性チェック）、レーン配線（直線 / 入れ子のマンハッタン）、フォールバックは A*。
- バイアス抵抗は信号経路から外して最後に枝として接続（経路を妨げない）。
- ルータ自身の不具合を 2 件修正: (1) 広幅トラックの強制割込み時、衝突相手を中心線上でしか探していなかった → 幅全体で探索。 (2) ビア周りの余裕が格子丸めで 0.02 mm 不足 → ビア半径に 0.03 mm、全体のクリアランスに 0.013 mm の余裕。
- 浮いた GND 島（ESD の GND ピン等）は、島の中へ GND ビアを自動追加（パッド上は避ける）。

### 訂正記録（2026-10-24）
- 結合区間の差動インピーダンスを **約 107 Ω → 約 104 Ω** に訂正。区間ごとの 2D 解を引く際、間隔を格子（0.10/0.15/…mm）に丸めており、実際の 0.13 mm を 0.15 mm の値で代用していたため。格子に 0.13 mm を追加して再計算。
- チャネル推定の**区間の並び順**を、配線の登録順から「配線のつながりを Core 側から順にたどる」方式に変更（2.4 mm の単線スタブが信号経路の中ほどに置かれていた）。反射の周波数特性が変わり、SDD11 の最大は −12.9 dB → −12.8 dB（CK）、他は −14.2〜−15.5 dB。

## 8. 是正が必要な事項（独立レビューによる、2026-10-24）

詳細と確認結果は `docs/シミュレーション方針と監査記録.md` §9。要点:

1. **TMDS 用 ESD の端子導通の想定が誤り**: §1 の表の「RCLAMP0524P ×2（4ch、10 ピン、素通し）」は、採用部品 C293965（DOWO 製、DFN2510-10L）では保証されない（I/O は 1/2/4/5、GND は 3/8）。信号線は連続配線にし、ESD は分岐接続にする必要がある。
2. **499 Ω 枝配線が長い（21〜53 mm）**: §7 の「バイアス抵抗は信号経路から外した」は評価から外してよい根拠にならない。抵抗を分岐点の近くに置き直す。
3. **対象速度は 720p60**: 1080p60 は GW2A のシリアライザ上限（1200 Mbps）を超える。
4. §3 の「ペア間スキュー：規定なし」は誤り（TI SLLA414A §2.3：ペア間 0.20×Tcharacter）。5 mm は自主目標。
5. §7 の結果表は、1・2 を含まない**是正前の推定**。是正後に再配線・再解析する。

## 9. 是正の実施（2026-10-24）
§8 の指摘を是正して再配線・再解析した。詳細・数値は `docs/シミュレーション方針と監査記録.md` §10。

1. **ESD**: ネットを 1 線 1 ネットに統合し、ESD の足（1/2/4/5 と 10/9/7/6）を基板上の銅の細線でつないだ。線路は連続した銅配線で、ESD は分岐。銅だけでの連続性を `check_continuity.py` で確認（8 線すべて OK）。
2. **499 Ω 枝**: 21〜53 mm → 11.5 mm 以下（D1 の N 側 11.5 mm は目標未達）。解析に実長・実位置で含めた。
3. **目標**: 720p60。観察帯域 〜1.5 GHz。
4. 再解析：悪い方のペアで SDD11 最大 -15.9 dB（〜1.5 GHz）、SDD21 @742 MHz -0.79 dB。是正前の枝では −4.2 dB / −2.6 dB。
5. §7 の表は「是正前」の推定。是正後の値は監査記録 §10。
