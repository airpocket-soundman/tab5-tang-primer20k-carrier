# Dock初回書き込み（2026-11-03）

## 結果と範囲

公式Dockに載せたTang Primer 20Kへ、低速LINK v0をSRAM書き込みした。
ユーザーからTab5ジャンパを外したと回答あり。後続の回答でDIPは全OFF、信号の直列抵抗は330Ωと確認。
Dockの版、各配線の現物照合・電圧測定は未確認。
外部Flashは変更していないため、電源断・再構成でこのプログラムは失われる。

- USB: VID 0403 / PID 6010、Converter A/B、UART COM26。
- Programmer: Gowin V1.9.12.04 build 2743、FT2CH channel 0、2.5 MHz。
- scan: ID `0x0000081B`（表示候補GW2A-18C/GW2AR-18C/GW2ANR-18C）。Coreの既存仕様に従いGW2A-18Cを指定。
- SRAM Program完了。別コマンドでStatus `0x00006020`、User Code `0x0000F924`を再読出し。
- User Codeは生成FSの値と一致。全SRAMビットの読戻し比較は未実施。
- ユーザーがLED点滅とUSB挿し直し後の消灯を確認。一時書き込みの起動と電源断による消失を確認した。
- 各ピンの電圧・Hi-Z、Tab5との実通信、DDR3、HDMIは未検証。

## ソースと再現

`fpga/platform/dock_link_top.v`は既存`link_bringup.v`を包むDock専用top。
27 MHz、電源投入リセット、SW0の同期とOFF確認後のARM許可を追加。
SW0をOFFにするとデータ出力許可を直ちに解除する。リセット後は再度OFF→ONが必要。
LED[0..3]は負論理でheartbeat（約0.621秒ごとに反転）、armed、ready、data OE。
以前のCSTコメントにあったCRC/timeout LEDは実装せず、実際の表示に訂正した。
通信コア、ジャンパのピン配置、8バイトv0コマンドは変更していない。

```powershell
python fpga/tools/build_dock_link.py --suite D:/tools/oss-cad-suite --output D:/tmp/tab5-dock-link-v0
```

OSS CAD Suite `20261102`を`D:/tools/oss-cad-suite`へ展開。
ビルドスクリプトは実機操作をせず、テスト、合成、配置配線、FS生成、ハッシュ記録まで。
パッカーは公式Primer20K向けapicula例に合わせ`GW2A-18`、T10入力用に`--reconfign_as_gpio`。

- コア試験: ID/512パターン、CRC/op拒否、途中DIR変更、timeout、ARM/reset/OEが合格。
- Python golden vectors: 583件合格。
- Dock top試験: 初期SW ONで非ARM、OFF→ON、非同期解除、リセット後の再ARM禁止が合格。
- 配置配線: LUT4 474/20736、DFF 178/15552、内部sys_clkの推定118.67 MHz、要求27 MHzで合格。
- bus_clk入力の専用配線を使えず通常配線へフォールバックした警告1件あり。bus_clkはコア内でsys_clk同期して使用。
  外部非同期入力の電気条件・CDCの実機検証や5 kHzでの通信成功を、この結果で保証しない。

成果物は`D:/tmp/tab5-dock-link-v0/`。
FS SHA-256: `9f8c2bd93b8ee0dfec4bb6de754a3ce9733e2d62a45d88989862ef1c37490cd7`。
`manifest.json`はビルド時点の記録（hardware_programmed=false）、書き込み後の事実は本書を参照。
`program-sram.log`、`read-status.log`、`read-usercode.log`を同フォルダへ保存。

書き込みコマンド（Programmerのbinディレクトリから）:

```powershell
./programmer_cli.exe --device GW2A-18C --operation_index 2 --cable-index 1 --frequency 2.5MHz --fsFile D:/tmp/tab5-dock-link-v0/dock_link_v0.fs
```

## 統合時の補足

`origin/codex/dock-jumper-gfx`をmainへ統合。初回書き込みのtop・記録は独立して保持し、
通常のLINK/GFX開発入口は`fpga/platform/dock/`と`fpga/builds/dock/`を使う。LED順序は両topで異なる。
T10はRECONFIG_NではなくSSPIのSI/D2兼用であることが統合資料で確認されたため、
初回用ビルドスクリプトも今後は`--sspi_as_gpio`を使用する。上記の実機結果とFSハッシュは
修正前の初回生成物の履歴であり、修正後のビルドや統合GFXの実機確認を意味しない。
