# NPU見積もり 上位FPGA比較（2026-11-04）

Sipeedのより大きいFPGAボードでNPUがどうなるかの**見積もり**。実機・合成での実証は無く、実機には触れていない。基準は [NPU実現性見積もり](NPU実現性見積もり_2026-11-04.md)（P4最良実測 約4.45GMAC/s＝13.7ms、全体実効 36.8〜91ms）。計算は [estimate_throughput.py](../fpga/npu/estimate_throughput.py) の `board_table()`、出力は [estimate_output_2026-11-04.txt](../fpga/npu/estimate_output_2026-11-04.txt)。

## 1. 公開仕様（Web取得）

| ボード（FPGA） | LUT4 | 18x18乗算器 | BSRAM | DDR3 |

| Tang Primer 20K（GW2A-18） | 20,736 | 48 | 約103.5KiB | あり(128MB)、現状未動作 |
| Tang Primer 25K（GW5A-25） | 23,040 | 28 | 1,008Kbit（約126KB、56ブロック） | なし（SDRAMアドオンのみ） |

138K Proは他にPCIe 3.0 x4、SFP+ x2、RISC-Vハードコアを持つ。分散SRAM(SSRAM)はDevice Version Bのシリコン不具合で無効。非Pro版138Kの個別仕様は取得していない。

## 2. 見積もり（9x9分割で乗算器数x2、仮定）

仮定：18x18を2個の9x9に分割できる（20Kと同じ考え方、**GW5系で未確認**）。クロック54MHzは20Kの実績値、100/150MHzは**GW5系の実績が無い仮定**。稼働率0.3〜0.6も仮定。通信は実効10MB/s（入出力73,620B＝7.4ms）、特徴マップ往復は考慮せず（compute律速の下限）。

| ボード | レーン | 54MHz 稼働0.6 | 100MHz 稼働0.6 | 150MHz 稼働0.6 |
|---|---:|---|---|---|
| 20K | 96 | 3.1 GMAC/s、通信込み27.0ms | 5.8、18.0ms | 8.6、14.4ms |
| 25K | 56 | 1.8、41.0ms | 3.4、25.5ms | 5.0、19.5ms |
| 138K Pro | 596 | 19.3、10.5ms | 35.8、9.1ms | 53.6、8.5ms |

（稼働0.3の値はスクリプト出力を参照。20Kの100/150MHzは仮定上の参考値で、実績は54MHzまで。）

## 3. 解釈（見積もり）

1. **25K**：乗算器が20Kより少なく、DDR3も無い。BSRAMは約126KBで重み0.6MBは入らない。**20Kより有利にならない。**
2. **138K Pro**：
   - 乗算器が約6倍、BSRAMが約7倍。**重み約0.6MBがBSRAM(約765KB)に収まる**ので、重みのDDR3読み出しが不要になる。特徴マップのみDDR3（または残りのBSRAM）。
   - 54MHz稼働0.6でも約19GMAC/s。**P4の最良実測(約4.45GMAC/s)に対し、通信込み(10MB/s)でも約10.5msで、P4最良の13.7msを上回る計算**（compute律速の下限。特徴マップ・DDR3律速は未考慮）。
   - 前回の見積もりで「DSP上限でも届かない」としたP4最良ケースにも、138K Proなら届きうる。ただし596レーンを全部使う設計は、累算器・重み供給・再量子化の制御資源が要り、**現実的な稼働率とLUT収容は未確認**。
3. **60K**：LUTは約3倍だが乗算器・BSRAM・DDR3は取得できず、評価不能。

## 4. 注意点

- 本リポジトリは **Tang Primer 20K Core 用キャリア**（ピン、電源、.cst/.sdc）。138K Proや25Kは別ボードで、**現キャリア・Dock・既存ビットストリームは使えない**。採用するなら基板・制約・LINK/GFXの移植が必要で、費用と作業量は別途見積もりが要る。
- 上位ボードのDDR3も、バス幅・実効帯域・コントローラ(IP)の可用性が未確認。20KのDDR3が未動作である事実は、上位でも同種の難所があるリスクを示唆する（推測）。
- 価格・入手性・消費電力は未調査。
- 結論：**P4の最良ケースに勝てる可能性が出るのは138K Pro級以上**だが、すべて見積もりで、クロック・稼働率・DDR3帯域は実測が必要。20Kで最小デモ（BSRAM内3x3 conv）を測って稼働率の実測値を得れば、上位ボードの見積もりの根拠も強まる。
