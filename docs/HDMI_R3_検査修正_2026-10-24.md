## 検査の具体的な変更

### 配置済みランド

基板に埋め込まれたU4/U5を新しく読み込んだライブラリ定義と比較する。部品の配置側・向きを参照へ適用し、相対座標へ戻して比較するため、正常な回転・裏面配置を誤って拒否しない。形状・サイズ・座標の差、パッド番号の欠落／重複、パッドとフットプリントのマスク／ペースト設定を検査する。比較許容差は位置／サイズ1µm、向き0.001度。

回転・裏面ケースは形状比較の試験であり、その位置で既存配線が導通することを保証するものではない。ネット名の一致と銅の実導通も分離し、後者は既存の `check_continuity.py` と `check_negative.py` で扱う。

メーカーの推奨ランドが無い問題は解消していない。採用した導出ランドに対する一致検査であり、製造先の実装確認を代替しない。

### 配線・区間分類

roleとPCBの中心線・層に加え幅を照合する。位置許容差3µm、幅許容差1µm。線を端点・重なりの境界で分割し、区間全体を評価する。接続点の共有だけでは重複としない一方、同じ区間を二つのroleが占有すると失敗する。stale判定も中点1点だけの判定を廃止した。許容差以下の退化した余分な銅セグメントも無視せず拒否する。

ビアは新しい `kicad/sim/tmds_via_policy.json` と照合する。今回確認した10個は、径0.6mm・ドリル0.3mm・F.Cu～B.Cuの貫通ビア。これは形状の検査で、ビアの電磁界寄生をモデルへ追加したものではない。配線を変更した場合は、位置・径・ドリル・層・型をレビューしてこのポリシーを明示的に更新する。検査の実行だけでポリシーを自動更新しない。

パッド内の除外長は既存の `tmds_sparam.py` が記録する。区間から除外したことをパッド遷移の電磁界解析の実装と混同しない。

### D2とRTL試験要求

公式 `video_top.v` の `{r,g,b}` に合わせ、RGB→エンコーダ→TMDS→Core→コネクタを表にした。D2のP/N入替補償は、画素の色値ではなく、エンコード後の10bit符号語／シリアルビット全体へ行う。制御期間を含めて検証する。単純に「青だけ反転して見えたら疑う」とする診断は削除した。

## 再現手順

以下はKiCad10.0のPython環境で実行する。検査スクリプトのインポートや実行にはpcbnewが必要。

```powershell
python -X utf8 kicad/sim/check_esd_footprint.py
python -X utf8 kicad/sim/test_esd_check.py
python -X utf8 kicad/sim/check_classification.py
python -X utf8 kicad/sim/test_classification_check.py
```

回帰試験JSONは `regression_esd.json` と `regression_classification.json`。各ケースの期待値、実際の合否、終了コードを保存する。エラーやJSON未出力を「期待した拒否」として数えない。

レポートは以下の順で再生成する（通常のPythonで実行可能）。

```powershell
python -X utf8 kicad/sim/make_audit_checks_page.py
python -X utf8 kicad/sim/make_manifest.py
python -X utf8 kicad/sim/make_report_page.py
```

`manifest_r3.json` は設計・モデル・検査・回帰JSON・追加レポート・この記録を含む。チャネルモデルの基準版 `baseline_commit=7929491` と検査修正の基準版 `checker_baseline_commit=91dc3b4` を区別する。manifestを埋め込む第3版HTMLそのものは、自己参照ハッシュを避けるため同じmanifestの対象から除外している。HTMLが属する版はGitコミットで固定する。
