# GPU LAB開発計画の参照と実行順序

2026-11-03。ユーザー指示により、機能を整理し、完了条件を確認して一段階ずつ進める。
アプリとDMAの実行計画の正本は `tab5-fpga-gpu/docs/GPU_DEVELOPMENT_PLAN.md`。
現在の作業ツリーでは `../../tab5-fpga-gpu-demo/docs/GPU_DEVELOPMENT_PLAN.md` にある。

最優先は、既存8bit配線でのDMA継続動作と通信高周波数化を並行すること。
実機では比較元を保持し、一つの変更ずつ評価する。現在は8MHz設定の実機比較まで通過したが、
転送ごとのAPB/Core/FIFO resetとenable/disableが残り、DMA継続動作の課題は未解決。
54MHz内部クロック候補は別作業ツリーに凍結し、合成・配置配線・実機の各段階を区別する。

その後、ポリゴン命令の一括化、モデル保持と回転デモ、DDR単体検証、DDRによる蓄積・二重バッファ、
共通演算・描画命令、全8シーン対応、最終デモと再現レポートの順に進める。
DDRを追加することで通信線の帯域が増えるとは扱わず、DMAの不具合を容量で隠さない。

本リポジトリはprotocol・FPGA・DDR controller/PHY・C codec・pin/電気条件・RTL/合成検証を管理する。
新しい共通仕様を確定する前に、ESP-IDF/MeOS/Linux本体と外部メモリ研究の要求を照合し、版を記録する。
GFX/MEM/NPUは用途別bitstreamを基本とし、同時搭載は資源・性能の測定後に判断する。
FPGA DDR3はLinuxの透過的なメインRAM増設ではない。
