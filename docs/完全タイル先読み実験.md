# Experimental complete-tile prefetch

Branch `codex/gfx-prefetch`, separate worktree `tab5-tang-primer20k-carrier-prefetch`, based on `6f196858560d88eeb63c6e038a5249f41bf79689`. The canonical five-MHz hardware-verified source is not changed by this branch. Commands, capability values, packet bytes, CRCs, pins and memory contents are unchanged.

Two16-bit registers hold alternating tile words. TILE_READ fills words0/1 in four system-clock cycles before reporting completion. The output byte selects directly from this parity cache, avoiding a synchronous RAM read after every transmitted word index change. After advancing to wordN, the consumed slot is refilled with wordN+1 using the existing RAM port and two refill cycles. Prefix/header indices are clamped to word0, and CRC indices to the final word, so unsigned preamble underflow cannot trigger false refills. Reset/abort discard prefetch state; new commands stop the previous stream.

The cache stores32 data bits plus small address/control registers; the design adds no memory array beyond these two words and is intended to use no additional BRAM or DSP. Actual mapped resource counts and routed timing remain pending and must be compared before programming. No hardware was accessed.
