# ESD部品（RCLAMP0524P）とフットプリントの照合記録

作成：2026-10-24（第2レポート監査 A1 への対応）。対象：U4・U5（TMDS ESD）。

## 1. 購入対象の固定

| 項目 | 内容 |
|---|---|
| メーカー・型番 | DOWO（東沃）RCLAMP0524P |
| LCSC / JLCPCB | C293965（BOMは `extended`） |
| パッケージ | DFN2510-10L（本体 2.5 × 1.0 mm、リード5本×2列、ピッチ0.5mm） |
| データシート | DOWO RCLAMP0524P **Rev.G1.00（2024/03/01）** 全4ページ。取得ファイル `RClamp0524P_DOWO_C293965.pdf`、SHA-256 `C6941D13961C2CC62C62AC10E274CF329A253F3BDF872E7D633B45DE0A0BE39A`（メーカー資料のため本リポジトリには再配布せず、ハッシュのみ記録） |
| 注意 | 設計初期はSemtech RCLAMP0524Pの「素通し（フロースルー）」前提でKiCad標準のUSON-10フットプリントを使っていた。DOWO品は**同名・別メーカーの別部品**で、データシートの端子定義が異なる |

## 2. データシートの端子定義（根拠ページ）

- p.1 Schematic & PIN Configuration、p.2 注記：「I/O pins are pin 1,2,4,5, GND pins are pin 3,8」。端子 6/7/9/10 は図中でNCと表記。
- よって、**入力側と出力側が内部でつながる（素通し）保証はない**。基板では、ESDの1/2/4/5を信号線のタップとし、6/7/9/10は銅の細線で各信号線へ接続している（線路は銅で連続。NC端子を信号線へ半田付けするだけで電気的には無害）。
- 容量：I/O−GND 0.4pF（最大0.5pF）、I/O−I/O 0.2pF（最大0.3pF）（p.2）。

## 3. 寸法の比較（p.4 Outline Drawing – DFN2510-10L と、基板のフットプリント）

| 項目 | データシート (min / nom / max) | 旧：KiCad標準 USON-10_2.5x1.0mm_P0.5mm | 新：`carrier:DFN2510-10L_RCLAMP0524P` | 判定 |
|---|---|---|---|---|
| 本体長さ D | 2.45 / 2.50 / 2.55 | 2.5 | 2.5（外形線） | 一致 |
| 本体幅 E | 0.95 / 1.00 / 1.05 | 1.0 | 1.0 | 一致 |
| ピッチ e | 0.50 BSC | 0.50 | 0.50 | 一致 |
| 端子間隔 Nd（両端の中心間） | 2.00 BSC（4ピッチ） | 2.00 | 2.00 | 一致 |
| 端子幅（信号）b | 0.15 / 0.20 / 0.25 | ランド幅 0.30 | ランド幅 **0.28** | 隣接ランド間 0.22mm |
| 端子幅（GND, 3・8）b1 | 0.35 / 0.40 / 0.45 | ランド幅 0.30（端子0.40より**狭い**） | ランド幅 **0.42**（隣のランドとの間隔 0.15mm） | 修正 |
| 端子長 L | 0.33 / 0.38 / 0.43 | ランド長 0.55 | ランド長 0.55（本体縁から外へ0.16mmのつま先、内へ0.02mmのかかと） | 一致（導出） |
| 列の中心間 | 本体幅1.0−L ≈ 0.62（端子中心） | 0.77 | 0.77 | 一致 |
| 端子番号と配置 | 1〜5が片側、6〜10が反対側、ピンnの反対側がピン11−n（p.4 図） | 同じ | 同じ | 一致 |
| GND端子 | 3・8（各列の中央、幅広） | 3・8（各列の中央） | 3・8（幅広） | 一致 |
| NC | 6・7・9・10（p.1） | 回路で信号に接続 | 回路で信号に接続（銅ストラップ） | 内部導通に依存しない |

**不一致の結論**：旧フットプリントはGND端子（幅0.40mm）に対しランド幅が0.30mmで不足していた。他は寸法上おおむね適合するが、データシートに**推奨ランドパターンの記載がない**ため、上表の新ランドは外形図から導いた値（つま先0.16mm、端子幅＋0.06〜0.08mm）で、メーカー推奨値ではない。専用フットプリント `kicad/lib/carrier.pretty/DFN2510-10L_RCLAMP0524P.kicad_mod` を作成し、回路・PCB・BOMへ反映した。

## 4. 実装方向

端子1の位置はデータシートの外形図にドットで示される（p.1のマーキング面「0524P」の左下付近）。基板は**番号で接続**しており、1〜10の機能は列の反転に対して対称な使い方（1↔10, 2↔9, 4↔7, 5↔6を銅で接続）のため、部品を180°回転して載せても電気的には同じ。ただし**ピン番号と機能の対応（I/O=1,2,4,5、GND=3,8）は回転では保たれない**ため、部品の向き（端子1）を実装図で確認する必要がある。JLCPCBのCPL（部品位置）で回転補正が必要になる可能性がある（注文時に3D・マーク位置を確認）。

## 5. 自動検査

`kicad/sim/check_esd_footprint.py`（KiCad python）が、ライブラリのフットプリントと基板上のU4/U5を上表の値と照合し、端子番号・ピッチ・ランドの被覆・GND端子・I/O端子・ストラップ接続を検査する（失敗時は終了コード1）。結果：`kicad/sim/esd_footprint_check.json`。さらにDRC、銅だけでの導通（`check_continuity.py`）、ストラップを除いた負の検査（`check_negative.py`）を再実行している。

## 6. 残る制限

- メーカー推奨ランドパターンは入手できていない（データシートにない）。製造先（JLCPCB）の部品ライブラリのフットプリント寸法を、注文時の部品確認画面で上表と照合すること。
- 実部品の半田付け評価（ブリッジ・つま先の濡れ）は試作で確認する。
