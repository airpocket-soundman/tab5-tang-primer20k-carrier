# OVP(C案) 過電圧遮断回路 ngspice 検証

USB-C の `VBUS_PD` に直列に入れる過電圧遮断回路(C案)を ngspice で検証した結果。
**使ったのは汎用の簡易モデルで、メーカー提供の SPICE モデルではない。ここに載せた数値は「この仮定下の机上値」であり、実機の遮断動作は未検証。** ジャンパ誤設定で PD の 12V が Core の 5V に入る事故への「保険」の位置づけで、12V 混入の実機試験はしない方針のため、遮断動作の根拠はこのシミュレーションだけになる(=下記の限界を踏まえて読むこと)。

## 再現方法

```
cd spark/usb-jtag-r5-ovp/sim-spice
python run_all.py          # 全ケース a〜g(約25秒)→ results.json を更新
python run_all.py a e g    # 指定ケースだけ再実行
```

- 通常の Python 3(検証は 3.12、64bit)で動く。追加パッケージ不要。
- KiCad 同梱の `ngspice.dll`(既定 `C:\Program Files\KiCad\10.0\bin\ngspice.dll`、ngspice-46)を ctypes で呼ぶ。場所が違えば環境変数 `OVP_NGSPICE_DLL` に指定。ダウンロード不要。
- `ovp_lib.py` = ngspice ラッパ + ネットリスト生成(import しても走らない)、`run_all.py` = ケース実行、`results.json` = 全数値(16コーナーの個別値を含む)。

## 回路とモデルの仮定

回路(確定値、`full/design/kicad/` の回路図と一致): Q9 AO3401A(PMOS 直列。S=VBUS_PD, D=VBUS_PGM, G=OVP_G)、R91 10k(VBUS_PD→OVP_G)、Q10 2N7002(D=OVP_G, G=OVP_NG)、R92 100k(VBUS_PD→OVP_NG)、Q11 MMBT3904(C=OVP_NG, B=OVP_B)、D12 BZT52C6V2(K=VBUS_PD, A=OVP_Z)、R93 1k、R94 4.7k。

| 素子 | モデル(汎用の仮定) |
|---|---|
| Q9 | PMOS LEVEL=1, VTO=-0.9, KP=4.07(Vsg=5V で Rds≈60mΩ)、Cgs 700p / Cgd 100p を外付け、ボディダイオード追加 |
| Q10 | NMOS LEVEL=1, KP=0.147, VTO を 1.0/1.6/2.5V で振る |
| Q11 | 標準 2N3904 BJT モデル |
| D12 | ダイオード BV=Vz(5mA時), IBV=5mA, **NBV で低電流域のドループを表現**(NBV=1/3/6)、RS=30Ω |
| 温度 | ngspice の `.options temp`。BJT の Vbe 温度係数は効くが、**ゼナー電圧の温度係数は入っていない**(Vz の ±5% で代用)。MOSFET の VTO は直接指定値で、温度では動かさない |

コーナー(16通り) = Vz ±5% × NBV 1/6 × 温度 -20/85℃ × 2N7002 Vth 1.0/2.5V(各2値の全組合せ)。公称 = Vz6.2 / NBV3 / 27℃ / Vth1.6。b では 27℃・Vth1.6 も加えた 36 通りでも確認し、16 通りと結果(最小・最大)が同一だった。

「遮断電圧」は **Vout(VBUS_PGM 側)のピーク電圧** で定義する(Core が実際に見る最大値)。ランプ時は併せてそのときの VBUS 側電圧(Vin@peak)も記録(Vout より約 0.03〜0.05V 高い)。

## 結果

### a. 正常時(DC、公称)

| VBUS | 負荷 | Vout | 電圧降下 | VBUS入力電流 |
|---|---|---|---|---|
| 4.75V | 1A(5Ω) | 4.690V | 60mV | 938mA |
| 5.0V | 1A(5Ω) | 4.940V | 60mV | 989mA |
| 5.5V | 1A(5Ω) | 5.442V | 58mV | 1089mA |
| 4.75/5.0/5.5V | 無負荷 | = VBUS | 0 | **0.47 / 0.50 / 0.55mA(静止電流)** |

- 1A 時の降下は 16 コーナーで 46〜77mV(約 0.05〜0.08V)。ほぼ Q9 の Rds(on) 分(≈60mΩ、仮定値)。
- 静止電流 ≈ VBUS/R91(Q10 オンで R91 に定常電流が流れる)≈ **0.1mA/V**。R92(100k)・D12 系は正常時は電流ほぼ0。

### b. スローランプ(0→15V、1V/ms、負荷10Ω+10µF)

| | Vout ピーク | Vin@peak |
|---|---|---|
| 公称 | **6.60V** | 6.63V |
| 16コーナー最小 | **5.68V**(Vz-5%, NBV6, 85℃, Vth2.5) | 5.72V |
| 16コーナー最大 | **7.25V**(Vz+5%, NBV1, -20℃, Vth1.0) | 7.27V |
| 幅 | 1.57V | |

- 時間刻み収束: 公称で tstep 20µ/5µ/2µ = 6.603/6.602/6.604V(±2mV 以内)。
- ばらつきの主因は **Vz の ±5%(約±0.3V)、NBV(ドループ)、温度(Vbe の温度係数。85℃で約 -0.3〜-0.5V、-20℃で上)**。2N7002 の Vth(1.0〜2.5V)は 0.01〜0.02V しか効かない。

### c. PD ステップ(5V→12V、30mV/µs)

Vout ピーク(負荷10Ω+1µF)。16コーナー最小〜最大: **5.87〜7.48V**、公称 6.81V(Vin@peak 6.96V)。遮断後(0.59ms 時点)の Vout は公称 0.25nV、全コーナー最大 18nV(=0近くまで落ちる)。

| 負荷条件 | 公称ピーク | 16コーナー最小〜最大 | 備考 |
|---|---|---|---|
| 10Ω + 1µF | 6.81V | 5.87〜7.48V | 遮断後 Vout ≈ 0 |
| 5Ω + 10µF | 6.71V | 5.76〜7.38V | 遮断後 2.5mV 以下 |
| 1kΩ + 1µF(軽負荷) | 7.10V | 6.17〜7.74V | 遮断後 0.59ms でも 4.7〜5.2V が残る(1µF×1kΩ の放電時定数 1ms のため。Vout はピーク以上に上がらず、負荷で放電していく挙動で、Q9 が開いている訳ではない) |

ランプより高く出るのはゲート時定数(R91×Cgs 約 7µs)分の遅れによる。軽負荷ほどピークが上がる点に注意。

### d. 高速ランプ(0→12V を 12µs = 1V/µs、参考値。負荷10Ω+1µF)

| R91 | 公称 Vout ピーク | 16コーナー最小〜最大 |
|---|---|---|
| 10k(現行) | 11.88V | 11.76〜11.93V |
| 4.7k | 11.30V | 9.62〜11.77V |

1V/µs の急峻な 12V 立ち上がりでは、**現行値ではほぼ保護できない**(Q9 のゲート時定数が限界。最終的には遮断して Vout は 0 に戻るが、立ち上がり中に 12V 近くまで通過する)。R91 を 4.7k にしても改善は限定的。PD 規格上の 5V→12V 遷移は 30mV/µs 程度(case c)で、この想定外の「瞬時 12V 印加」(例: 12V 入力に配線ミスで直結)には効かない前提で見ること。

### e. 5.5V 給電での誤遮断なし

全 16 コーナー + 公称で **誤遮断なし**(Vout は 1A 負荷で 5.43〜5.45V = 降下 55〜75mV、無負荷では 5.50V)。最小は 5.425V(1A)。5.5V での最も近いコーナーは「ゼナー -5%・NBV6・85℃」で、遮断窓の下限(5.68V)との余裕は **約 0.18V**。

### f. 部品値感度(遮断窓 = 16コーナーの Vout ピーク最小〜最大、ランプ 1V/ms)

現行(Vz6.2 / R91 10k / R93 1k / R94 4.7k): 5.68〜7.25V(幅 1.57V)。

主要な行(全 54 構成は `results.json`):

| 変更 | 窓 | 備考 |
|---|---|---|
| 現行 | 5.68〜7.25V | |
| R91 4.7k / 22k | 5.68〜7.25V / 5.68〜7.25V | R91 はスロー側の遮断電圧にほぼ無関係(高速側 d にのみ効く) |
| R94 2.2k | 5.94〜7.44V | 下限は上がるが上限も上がる |
| R94 10k | 5.48〜7.14V | 下限が 5.5V 未満(NG) |
| R93 4.7k | 6.05〜7.79V | 窓が上にずれる |
| Vz 5.6V(R93=1k, R94=4.7k) | 5.10〜6.62V | 下限が 5.5V 未満(NG) |
| Vz 5.6V, R94=2.2k | 5.35〜6.80V | 下限が 5.5V 未満(NG) |
| Vz 6.8V | 6.25〜7.88V | 上限が大きい |

**窓の幅は 1.44〜1.93V でほとんど動かない**(ばらつき幅はゼナー許容差・ドループ・温度で決まり、R の選択ではほぼ縮まらない)。窓全体を動かせるだけなので、「下限 ≥ 5.5V を保ったまま上限を下げる」余地は小さい。

追加の細かい走査(Vz=6.2V固定、R93=330〜1k、R94=4.7〜10k、`results.json` の `fine_scan_vz6p2`):

| R93 | R94 | 窓 | 現行比 |
|---|---|---|---|
| 330Ω | 4.7k | 5.61〜7.14V | 上限 -0.10V、下限 -0.07V |
| 330Ω | 6.8k | 5.53〜7.13V | 上限 -0.12V、下限 -0.15V(余裕が5.5Vに接近) |
| 680Ω | 4.7k | 5.64〜7.20V | 上限 -0.05V |

**推奨変更: 実質なし。** 5.5V を下回らず上限が下がる組合せは R93 を 330〜680Ω に下げる場合だけ見つかったが、上限の低下は最大でも約 0.1V で、このモデルの精度(汎用モデル、Vz の温度係数なし)に比べ小さく、有意とは言えない。しかも R93 を下げると g の通り高電圧時の R93 損失が増える(330Ω・20V で約 0.45W)ため、採用は勧めない。現行確定値(6.2V / R93=1k / R94=4.7k)のままでよい。

### g. 高電圧の定常(Q9 がオフを保つか、定格内か)

| | 12V 定常 | 20V 定常 |
|---|---|---|
| Vout(16コーナー最大) | 18nV(≈0) | 18nV(≈0) |
| Q9 の Vsg | 0V(ゲートが VBUS に引かれてオフ) | 0V |
| D12 電流(最大) | 5.3mA | 12.9mA |
| D12 電力(最大)/ 定格 350mW | **32mW** | **86mW** |
| Q11 ベース電流(最大) | 5.1mA | 12.7mA |
| Q11 電力(最大) | 4.2mW | 11.8mW |
| R93 電力(最大) | 28mW | **166mW** |
| R92 電力(最大) | 1.4mW | 4.0mW |
| VBUS から流れる電流(最大) | 5.4mA | 13.1mA |

- 12V 定常: Q9 はオフを保ち Vout ≈ 0。D12 は 32mW(定格 350mW の約 9%)、Q11 は 4mW で、いずれも定格に対して大きな余裕がある。R93 は 28mW で 0603(一般に 100mW)の約 28%。
- 20V 定常: D12 は 86mW、Q11 は 12mW で余裕あり。**ただし R93(1k, 0603)が最大 166mW で、0603 の一般的な定格 100mW を超える**。20V を長時間かけ続ける使い方は想定外(目的は 12V 誤接続の保険)だが、PD 20V 要求がありうる構成なら R93 の定格・パッケージ(0805 以上 / 抵抗値を上げて電流を絞る)を見直す余地がある。Q9 の Vds(AO3401A は -30V)、Q10 の Vgs、Q11 の Vce も 20V に対し定格内。
- ここでの電力は VBUS が定常的に 12V/20V のままのときの値(遮断後の定常状態)。過渡の過電力は見ていない。

## 解釈

1. **遮断電圧の窓**: スローな上昇(1V/ms)で Vout ピーク 5.68〜7.25V、公称 6.6V。PD ステップ(30mV/µs、負荷10Ω+1µF)では 5.87〜7.48V と、ゲート遅れ分だけ約 0.2V 高く出る。軽負荷(1kΩ)では最大 7.7V まで出る。窓の幅(約 1.6V)は Vz の ±5% と NBV と温度で決まり、R の選択では縮まらない。
2. **Core への示唆**: Core 側 5V ラインの絶対最大定格は不明。この回路は「12V がそのまま入る」ことは防げる(遮断後 Vout≈0、12V 定常でも Q9 はオフを保つ)が、**遮断が働くまでの間に約 6〜7.7V までは Core 側に出る**。その電圧が Core の絶対最大定格(通常 5V 系の部品は 6V 前後が多い)を超えないことは、この回路では保証できない。Core の定格が判明したら、この値(PD ステップで最大 7.5〜7.7V)と照合すること。
3. **正常動作への影響**: 5.5V でも誤遮断なし(窓の下限 5.68V との余裕 約 0.18V)。1A 給電時の電圧降下は約 60mV(46〜77mV)、静止電流は約 0.5mA(5V 時)。
4. **保護できない場合**: 1V/µs 級の急峻な 12V 印加(d)では Vout が 12V 近くまで抜ける。ゆっくり変化する想定(PD の遷移、ジャンパ誤設定後の電源投入)に対する保険であって、急峻なサージや ESD に対する保護ではない。
5. **限界**: (i) ネットリストは汎用簡易モデル(Q9/Q10 は LEVEL=1 の概算で Rds・Cgs・Vth の実測ばらつきを含まない、D12 は NBV による低電流ドループの近似、温度係数はゼナーに入っていない、実デバイスの製造ばらつき・リーク・寄生は未考慮)。(ii) 実機で遮断動作を確認していない(12V 混入の試験はしない方針)。(iii) よって遮断電圧の窓は「机上値」で、実機の窓はずれうる(特に Vz の温度係数と低電流域の立ち上がりは実部品次第)。「保険としての位置づけ」を超える性能保証には使わないこと。

## 既知値との照合

| 項目 | 既知値 | 本再実行 | 判定 |
|---|---|---|---|
| 公称遮断 | 6.6V | 6.60V | 一致 |
| 窓 | 5.68〜7.26V | 5.68〜7.25V(Vin@peak 側は 5.72〜7.27V) | 一致(差 0.01V は tstep・定義の差) |
| 5.5V 誤遮断 | なし | 全16コーナーでなし | 一致 |
| PD ステップのピーク | 5.9〜7.5V | 5.87〜7.48V | 一致 |

食い違いはなかった。なお f の表は刻み 10µ・12V ランプで算出しており、現行構成は 5.681〜7.246V(b の 5.680〜7.249V と 3mV 以内)。

## ファイル

- `ovp_lib.py`: ngspice ラッパ、ネットリスト生成、コーナー定義

- `results.json`: 全数値(16コーナー個別値、f の 54+20 構成、g の電流・電力を含む)
