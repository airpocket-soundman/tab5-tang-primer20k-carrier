# Spark版：実装業者と組立担当向け指示

対象は125×78mmのSparkフル機能版。現行データは見積・レビュー用。業者承認と実物嵌合確認後に発注確定する。

## 業者へ渡すもの

`manufacturing/spark-full-review-2026-10-26/` 内のGerber ZIP、JLC BOM、JLC CPL、表裏組立図、manual-assembly.csv、dnp.csv。BOM/CPLは99参照番号で一致する。KiCad座標は原点(2,79)mm、右が+X、上が+Y。回転はKiCad規約のためJLCプレビューで照合する。

J4の204端子Core受けソケットはPCBA必須。モジュール本体はBOMに含めない。J5 HDMIの19信号端子と4つの貫通固定タブをすべて業者がはんだ付けする。J2 USB-Cの固定シェルも実装対象。工程上実装できない端子を未接合のまま納品しない。SW1/SW2はC480272、高さ5.5mm、同電位ペアを組立図と照合する。

## 秋月から購入して手付けするもの

| 部品 | 組立上の注意 |
| --- | --- |
| J1 MJ-179PH/106568 | センタープラスの安定化12V専用。ランド端子1がDC_RAW、2/3がGND。プラグ未挿入/挿入の両状態で中心と外周の短絡がないこと、中心がDC_RAWへ導通することを確認 |
| SW3 KSD22/108922 | 未使用を含め初期は両回路開放。基板のローカル端子1/4を閉じるとFPGA用5V停止、開くと動作。2/3は未使用。スイッチ本体のON刻印はFPGA停止状態になるため完成品の表示を合わせる |
| J3 PH-2x40SG/100082 | 2×15へ切断し裏面実装。2台分を1本から切り出す。ユーザー確認済みの鏡像列配列を維持し、左右/表裏を一般的な番号順で推測しない。Tab5と嵌合高さ・向きを確認してからはんだ付け |
| JP1 PH-1x40SG/100167 | 1×2へ切断。初期はショートピンを装着しない |
| JP1用2228AG/103878 | 別梱包。両側電源とGPIO初期状態を検証してからBUS ARMを有効にする |

J6/J7/J8等のDNPは初回購入・実装しない。DNP抵抗や追加容量を意図なく実装しない。Tab5とTang Primer20K Coreはユーザーが別途購入し、業者PCBAの部品支援へ含めない。

## 初回通電

1. Tab5とCoreを外し、JP1開放、SW3両回路開放で目視・抵抗測定。はんだブリッジ、電源と接地の短絡、電源部品の極性を確認。
2. 電流制限した安定化12Vから投入し、無負荷の5V/3V3を測定。SW3の使用回路を閉じるとCore用5Vが停止することを確認。PD側も対応電源で要求電圧を実測し、5V/9V入力時の動作を想像で保証しない。
3. 電子負荷で5V電圧と温度、電源切替、停止/再起動を測定。Tab5側HVINを含む負荷予算を確認。
4. 電源を切ってCore/Tab5を装着。片側電源だけの状態でI/Oへの逆給電、監視出力、バス隔離、GPIO初期状態を確認。
5. JP1有効化後、弱駆動/SLOW・1MHz・DATA setup/hold各250ns以上・DIR切替500ns以上で往復CRC。DDR3試験と演算照合を先に実施し、速度上昇とHDMIを段階的に評価。

筐体の図面は現時点でコンセプト。部品/カード高さ、コネクタとケーブルの挿抜、Tab5背面、絶縁スペーサ、温度と通風を実物で確認してから造形する。
