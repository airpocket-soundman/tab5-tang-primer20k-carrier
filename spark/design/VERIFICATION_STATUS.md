2026-10-26。125×78mm、4層、HDMI、USB PD12V、バレル12Vを保持。従来版・A/B/Cは保存し、別作業フォルダの883ファイルが開始時のハッシュと一致することを確認した。

## 完了した設計作業

- J1を秋月106568/MJ-179PH専用ランドへ変更。端子1がセンタープラス、端子2/3が接地。図面の1×3.5mmスロット、側端子Y4.9mmを反映。
- SW3を秋月108922/OTAX KSD22へ変更。2回路中1回路でBUCK_ENを接地し、残りを明示的NCとした。7.6mm列間隔、2.54mmピッチ、0.8mm穴、両面マスク開口。未使用端子を避けるBUCK_ENの局所迂回を実施。
- PCBAは99部品・41行。SW1/SW2はC480272、CoreソケットはC22471982、HDMIは固定シェル端子を含めてC916313の業者実装を要求。手付け4部品は秋月へ集約。
- KiCad回路図から出力した実ネットリストの482接続端子をモデルと照合。KiCad設定済みルールの全severity DRCは違反0・未配線0、ERCエラー0。電源・隔離・M5-Bus等の32項目とHDMI導通検査も合格。

## 次に解消する残件

### EasyEDA内の再計算（追記）

API GatewayのブラウザーWorker内へ公式NGspice46 WASMを読み込み、電源6条件と通信150条件を実際に再計算した。製造用回路図全体を自動SPICE化したものではなく、従来の解析用等価回路を同じ条件で再実行した結果である。GUI操作、既存の計算値の結果イベントへの注入、外部PythonでのSPICE代行は行っていない。

電源6条件は電圧範囲内で、電圧指標の差は従来結果に対して最大約0.0173mV。通信150条件は全て数値計算完了、合否分類150/150一致、端子電圧極値の差は最大約0.0253mV、整定時間の差は最大約0.00913ns。受信端150/150合格・送信端60/150合格という従来の制約もそのまま再現した。PD入力モデルの0Ω抵抗を1e-12Ωへ置き換える警告は記録し、物理モデルの問題と混同しない。

周期モデル16条件も再計算し、全閾値判定が一致、1MHzは4/4合格。周期波形の書き出しは10万点上限への対応として計算後に元の出力間隔100psへ補間している。ソルバー条件は変更せず、サンプル電圧の差は最大4.21mV。通信150条件の過渡極値は補間せず比較した。

実行元のコミット・バイナリハッシュ、再現スクリプト、比較表、波形ハッシュ、重ね合わせ図は `../simulation/easyeda-wasm/` を参照。HDMIの4ポート近似解析は従来の外部計算結果であり、EasyEDA内で再実行済みとはしない。解析環境の照合が完了しても、下記の実物・実装・応募資格の残件は解消されない。
