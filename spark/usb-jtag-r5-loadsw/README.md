# r5l：SW4を信号専用にして、+5VをPMOSのロードスイッチで通す変種（PoC・発注候補）

2026-11-06。**実機未検証。リリースではありません。** r5s（`../usb-jtag-r5-switch/`）の派生で、r5s、r5、r5c、r4 のファイルは変更していません。

## 何を変えたか

- r5sでは、SW4（G-Switch SS-23D03-G080）が+5Vレールの電流を通していた。この部品の電流定格は、メーカーのデータシートで **0.3A・50V DC**（LCSCの掲載値1Aと食い違う）。
- r5lでは、SW4は**信号だけ**（ゲート駆動とCFG1）。+5Vの電流は、背中合わせのPMOS（AO3401A）が通す。
  - RUN経路 Q11・Q12（BUCK_5V → +5V）、PGM経路 Q13・Q14（VBUS_PD → +5V）。
  - PGM経路の過電圧ガード Q15・D12・R95（VBUS_PDが約7Vを超えたら、PGM経路をオフにする）。
- 追加11部品（Q11〜Q15、D12、R91〜R95）。基板の部品位置・配線の他の部分は、r5sのまま。

詳しい検討・SPICE結果・未確認事項は `../../docs/r5s_SW4ロードスイッチ式の検討_2026-11-06.md`。

## 検証したこと

- ERCエラー0、PCB DRC違反0、未配線0（`full/design/kicad/sim/`）。
- 回路図と基板のネット照合: 761ピン、不一致0。r5sとの基板の差分は、SW4の電源配線の削除24点と、SW4の3ピンのネット変更だけ。
- `verify_design.py`: PASS（SW4のスライダ位置モデル、ロードスイッチの接続、危険な組合せなし）。
- SPICE（汎用モデル）: RUN／PGM／OFF、DCのみ、VBUS 12V誤使用（+5V＝0V）、5.5V給電で誤遮断なし。+5Vのピークは、ランプで5.5〜7.7V。

## 既知の制約（PoCとして受け入れる範囲）

2026-11-07の再監査（`../../docs/r5l基板再監査_2026-11-07.md`）を受けて、次を明記する。

1. **過電圧ガードは、定格内に収める保護ではない。** VBUSがランプで上がるとき、+5Vのピークは最大約7.7Vで、**3.3V LDO（U3 TLV1117LV33）の絶対最大入力6V（動作範囲は2〜5.5V）を超える**。ガードは、12VのままPGMへ切り替えるなどの誤使用で、被害を小さくする「保険」にとどまる。約7Vで切る6.2Vゼナー方式は、PDの5V許容（5.5V）を通しつつ5.5V超を切る、という窓に原理的に合わない。回路は、PoCとして作り直さない。
2. **運用ルール:** RUN／OFF／PGM（SW4）と、JP3、JP1の切り替えは、**電源アダプタとUSB-Cを外した無電源の状態で行う**（シルクの `POWER OFF!` のとおり）。通電中のモード切替は、保護の対象に入れていない。
3. **USB D+／D−:** 差動ペアとして並べて配線していない。経路長はD+約17.0〜17.5mm、D−約25.1〜27.0mm（差約8mm）。90Ωの積層設計も未確認。ハイスピード動作は、実機で確認する（ハイスピードで認識できない場合は、フルスピードの動作を確認する）。

### Core（Tang Primer 20K）のI/O電源（VCCO）の条件

このキャリアは、SODIMMの164・166（Bank 0/1の外部VCCO）と、170・174（Bank 7の外部VCCO）を**未接続**にしている。一方で、Bank 0、1、7のピンを使う（Bank 7には、LINKの F_D5、F_D6、F_D7、F_DIR などが載る）。

- Core回路図の読み取り（`../../docs/reference/README.md`、`../../docs/Dockジャンパ試験_配線とFPGA構成_2026-10-28.md`）では、**既定のCoreは R5（Bank 0/1）と R9（Bank 7）が付いていて、VCCOはCore内部の3.3V**。この場合、164・166・170・174を未接続にしても、該当バンクは3.3Vで動く。
- **R6（Bank 0/1の外部選択）または R13（Bank 7の外部選択）が付いているCoreでは、キャリアがVCCOを供給しない限り、該当バンクが無給電になる。**
- 公式Dockは、164・166に3.3Vを接続し、170・174は未接続にしている（Bank 7は、Dock上でR9の実装を確認できないため、使わない運用）。**Dockで動いたことは、このキャリアでBank 7が動く証拠にならない。**

**このキャリアで使うCoreの条件（組立・受入）:**
1. R5とR9が実装されていて、R6とR13が実装されていないこと。Coreを挿す前に、実物で目視（または抵抗の導通）で確認する。
2. Coreに5Vだけを与えて通電した状態（キャリアには挿さない、またはキャリアの5Vだけ入れる）で、**Core基板上の VCCO7 のノード（R9またはR13の、FPGA側のパッド、またはFPGA近くのVCCO7のデカップリング容量）とGNDの間の電圧が3.3Vであること**を確認する。**SODIMMの170・174の電圧では、確認できない**（R13が実装されていなければ、170・174はCoreの内部にどこにもつながらず、電圧が出ない。R9実装・R13非実装が、この基板の想定する正しい状態）。同様に Bank 0/1 は、R5またはR6のFPGA側パッドで確認する。
3. 確認できていない間は、「Bank 7（F_D5〜F_D7、F_DIR、GPIO0〜4、F_LED0〜1 など）の動作は未確認」として扱う。

この条件は、実機のCoreで確認するまで、**未確認**である。
