# r4 重要部品のランド形状確認

2026-10-26。対象はU1 CH224K、フル版L1 SRR1260-150M、C7 10TPB220M、廉価版U3 XC6206P332MR-G。回路・基板・CPLの変更は行っていない。

結論：公式ライブラリとのランド中心差は、メーカー端子と現行ランドの不整合を意味しない。下記のメーカー図面・現行寸法から、今回の4部品にランド中心差だけを理由とした再配線は必要ない。CPLは番号・極性を保った公式座標軸への回転を使い、推奨ランド長の違いを部品本体の移動と誤認しない。

| 部品 | 確認した寸法と判定 |
| --- | --- |
| U1 / CH224K | WCH V2.1 p15のESSOP10はピッチ1.0mm、端子外端間6.0mm、足長0.5mm、幅0.43mm。現行ランドはピッチ1.0mm・1.675×0.6mmで、本体中心から1.8～3.475mm。公称端子足2.5～3.0mmを覆い、外端間最大6.2mmに対しても外側余白0.375mm。露出パッド2.1×3.3mmは公式ライブラリと一致。中心差約0.363mmは主に外側toe長の差。 |
| L1 / SRR1260-150M | Bourns推奨は2.9×5.4mmの2ランド、内側間隔6.8mm、中心間9.7mm。現行ランドと完全一致。公式汎用ライブラリの3.5×5.6mm・中心間約11.375mmに置き換えない。 |
| C7 / 10TPB220M | Panasonic D3Lの本体7.3±0.3mm、端子長1.3±0.2mm、端子幅2.4±0.1mm。現行ランド2.07×2.59mm、中心間6.24mmは公称端子の2.35～3.65mmを覆う。最大本体長での端子外端3.8mmに対してランド外端4.155mm。中心差約0.317mmは主にtoe長の差。極性はpin1=+を維持。 |

供給元ランド矩形と現行ランド（角丸を含む）の面積交差も算出した。公式ランドのうち交差する最小比率は、U1約80.6%、L1約65.1%、C7約82.3%、Lite U3約89.6%。これは同じ端子に対する異なるはんだランドの比較であり、端子接触面積の比率ではない。とくにL1はメーカー推奨と現行が一致するため、65.1%を不良率や搭載不可と解釈しない。

## J1の座標原点補正

XKB C381116 / DC-005-5A-2.0のA1図面（2025-04-22、PCB LAYOUT TOP VIEW）は、pin1を原点とするとpin2=(-5.9,0)、pin3=(-3,-4.7)mm。現行穴はこの図面どおりで、3穴とも1×3.5mmの長穴。

供給元ライブラリはpin1≈(3,2.351659)、pin2≈(-3,2.351659)、pin3≈(0,-2.351659)mm。pin2間隔だけ6.0mmとなっており、図面の5.9mmと0.1mm違う。最小二乗移動(-2.966582,-2.350553)mmは、この差を平均したx+0.033418mmの偏りを含む。

原点は図面に基づく(-3,-2.35)mmの変換を使う。したがってFullのCPL(15,29)は(12,26.65)、Lite(15,64)は(12,61.65)mm。これは供給元座標枠への変換であり、現行の基板穴を動かす変更ではない。
