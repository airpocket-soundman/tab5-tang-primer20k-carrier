## 3. 応募資格で設計に影響する事項

現行FAQ：EasyEDA Proで設計し、完全なプロジェクトファイルを公開する。ライセンス選択は任意との記載だが、本プロジェクト側の公開ライセンスと第三者資料の権利整理は別途決める。公式スタッフKarlaの2026-01-23回答は「100%」EasyEDA Proで設計する条件。2026-06-25にはKiCad等を尋ねた質問へEasyEDA必須と回答している。

既存KiCadの単純取り込みで条件を満たす根拠はない。ネイティブ作成、ライブラリ照合、回路/ERC、基板/DRC、BOM/CPL、端子番号を再検証する。工学参照版をEasyEDA設計済みと表示しない。

完成品と筐体が必要。開発基板だけは不可。したがって「汎用キャリア基板」単独ではなく、Tab5 FPGA Workstationという動作する組込システムを提出する。ただしこの構成が完成品として採択されるかは主催確認事項。

過去Sparkプロジェクトの再提出は不可。現行FAQは新しいテーマの新規作品を要求。以前から開発していても未支援なら応募可という2026-02-25のスタッフ回答もあるため、本件の既存GitHub公開・派生設計であることを開示して確認する。初出不要を、過去支援作品の反復参加可と解釈しない。

支援されたプロジェクトは取り下げ不可。削除時には公式アカウントへ読取専用バックアップされる旨がある。作品の権利を保持しつつ、姉妹サイトOSHWHubへの再掲載を許容する条件も確認。

## 4. 「応募受理」と「支援承認」の区別

募集ページの参加工程は以下。

1. Sign Up：参加登録自体は審査不要。
2. Create Project：回路図・PCB設計を完成する。
3. Apply Coupon：審査を待ち、承認後に注文・材料受領。
4. Project Completed：製品写真を追加し、完成扱いにして公開。

完成プロジェクトとして公開・承認された後はクーポン申請できない注意書きがある。**非公開の設計完成→支援申請→製作→動作実証→最終公開**を基本順序とし、材料審査と完成公開の審査を混同しない。応募登録だけで自動的に全費用が支給される制度ではない。

受賞規則コメントでEasyEDA@Bobは2026-09-02に、適格な全プロジェクトへ開発中のPCB/PCBA支援を1回提供すると回答している。よって受賞が支援開始の前提ではない。主催者が本件を適格と判定し、個別注文にクーポンを発行するまでは支援未確定。

同時に支援できるのは1プロジェクト。募集ページの高品質作品向け複数材料申請の記載と、旧材料記事/スタッフ回答のPCBA1回という記載は区別する。初回1ロットのみを計画に入れ、再試作支援は確認前に算入しない。

## 5. 材料申請の具体条件

[公式Materials application instructions](https://oshwlab.com/article/Materials-application-instructions)（本文更新2025-12-17、2026年の公式回答あり）：

- 設計未完成だと材料申請は却下される。
- 実際に必要な材料のみ。在庫品のみ対象、備蓄や工具など無関係な購入は不可。
- 注文金額は5,000米ドル以下という記事の紹介文。これは5,000ドルの補助金保証ではない。
- PCB5枚が標準、SMT/PCBA2枚。2026-04-08にスタッフも5枚PCB・2枚PCBAと確認。
- PCBとPCBAの両サービスを利用。PCB申請とSMT申請の2段階。通常納期で申請。
- サービスに応じた申請フォーム、正しい注文番号・価格、仕様画面と明細のスクリーンショットが必要。
- クーポンは受領後7日以内に使用。承認後の自己都合による再申請を認めないとの注意があり、未払い注文の部品・仕様を先に固める。

記事の特殊工程に関する英語は誤記を含む可能性がある。不要な特殊材料・高仕様・表面処理を申請しない。本案の4層・1.6mm・既存積層と、細ピッチソケットに必要な表面処理は見積時に根拠を示す。ENIG等の承認条件は担当者に確認する。

## 6. 支援対象と自己負担

現行FAQ：材料と送料の約80%を支援し、税は参加者負担。JLCPCBで入手できない材料は自己購入。対象サービスのクーポン発行であり、自由に使える現金の開発助成ではない。

| 項目 | 本案の扱い |
| --- | --- |
| キャリアPCB、SMD部品、PCBA | 支援申請候補。個別承認待ち |
| Coreソケット、USB-C、HDMI、PCBA操作部品 | 実装サービスの見積に含めて申請。取扱・治具・固定端子工程を確認 |
| 保護筐体3Dプリント | JLC3DP支援候補。CADと必要数量を用意して別申請 |
| 国際送料 | 公式では支援範囲。個別クーポン上限を確認 |
| 税金 | 自己負担 |
| Tab5・Tang Primer 20K Core | ユーザー購入。申請対象外 |
| LCSCから個別購入する手付け部品 | Spark支援は未確認、予算では全額自己負担 |
| 工具・無関係な部品・余分な在庫 | 申請しない |

LCSCについては、材料記事コメントでEasyEDA@Bobが2026-03-16に「現状JLCPCBクーポンのみ、LCSCクーポンはポイント交換」と回答。2026-06-29にもポイント交換を案内。**LCSCとJLCPCBが同グループであるだけでは、LCSC単品注文が支援対象にはならない。** JLCPCBの部品ライブラリで買った部品もPCBA専用で単体配送不可という販売条件がある。未実装3枚の手付け用部品を同じPCBAクーポンで入手できるとは見込まない。

100ドルの完成特典クーポンは初回発注の資金に算入しない。受賞賞金も設計・初回試作の資金源に含めない。

## 8. 審査と実演の準備

受賞規則：一次審査は独創性30%、実用性25%、オープンソースの利用しやすさ20%、技術実装15%、環境面10%。最終配点は専門家50%、専門レビュー30%、コミュニティ影響20%。賞金は30,000ドル×1、10,000×2、3,000×5、1,500×10、500×10（合計28件・85,000ドル）。

本案では再利用できるモジュール構成、既存Tab5を活用すること、通信・電源保護、実測と再現手順を示す。GPU30FPSは目標で実証済みと書かない。受賞作品は本部へ送付して機能確認を受ける。国際送料はEasyEDA負担とのFAQ。Tab5とCoreも送付が必要か、予備機の必要性、返却条件は主催確認事項。

## 10. 推奨する実行順序

登録情報と資格確認 → 非公開プロジェクト → EasyEDAネイティブ設計・検査 → 筐体設計・全BOM → 部品在庫/実装レビュー → 未払い見積 → 材料申請承認 → クーポン発行 → 7日以内の注文 → 組立/実測 → 完成品・動画・完全ファイルの公開 → 2027-03-31までに提出。
